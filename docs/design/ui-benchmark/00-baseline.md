## 1. 화면 공통(헤더·전역) — evidence: ours-g1-dashboard-desktop-rea, ours-g1-dashboard-mobile

- 맨 위 한 줄에 지역 · 기준일(`2026-10-14 · 리비전 4`) · 상황 5개(`기본 / A 가점 높음(실거주) / B 가점 낮음·소액 자기자본 / C 시세차익 우선 / D 즉시 구매`) · `API 토큰 · 토큰 설정됨` · 테마 버튼이 같은 무게로 나온다. 초보가 첫 줄에서 "리비전", "API 토큰"을 먼저 읽는다. 리비전 선택지가 같은 날짜로 4개(`리비전 4/3/2`, 무표기) 있어 무엇이 다른지 모른다.
- 상황(시나리오) 토글이 "가점 높음/낮음"이라는 말을 쓰지만 앱 어디에도 **가점 계산·커트라인 정보가 없다**(아래 §4 여정 Q6). 토글을 누르면 순위만 바뀐다는 설명이 없다.
- 모바일: 상황 토글이 잘려 `기`, `A 가점 높`, `B 가점 낮음·소`, `C 시세차`, `D 즉시`로 보인다. 메뉴 7개가 가로로 넘쳐 `데이터·운`에서 잘린다. "모바일에서는 읽기 전용입니다" 안내는 있다.
- 메뉴 순서가 `홈 · 단지 리스트 · 비교 · 시나리오 · 지역 시장 · 데이터·운영 · 보고서`. 초보에게 필요 없는 운영 화면(데이터·운영)이 같은 무게로 노출된다. 단지 상세에 들어가도 메뉴는 `단지 리스트`가 켜진다(현재 위치가 "상세"라는 표시는 페이지 제목뿐).
- 하단 고정 바 `투자 권유 아님 · 상대 비교`는 모든 화면에 있다(D7 준수). 풀페이지 캡처에서 이 고정 바가 본문 중간을 가린다(`ours-g1-dashboard-desktop-full`, `ours-g3-detail-32-desktop-full`) — 실제 스크롤에서는 마지막 줄이 바에 덮인다.
- 모든 수치가 점선 밑줄 버튼(누르면 출처 패널)이고 바로 옆에 라벨 배지(`확인됨`/`추정`/`추정(산술)`/`추정(판정기 noul)`…)가 붙는다. 점선 밑줄이 "누르면 출처"라는 안내는 화면 어디에도 없다.

### G1 홈 대시보드 (`/?scenario=base`) — ours-g1-dashboard-desktop-rea, ours-g1-dashboard-desktop-full, ours-g1-dashboard-mobile

**첫 화면 3초 테스트**

| 초보가 실제로 먼저 읽는 것(크기·위치 순) | 먼저 읽어야 하는 것 |
|---|---|
| 1. 핵심 지표 카드 5개의 큰 숫자 `6`, `3`, `3,729 세대`, `2026`, `2026-10-13 (D+1)` — 무엇의 개수인지 맥락 없음 | 1. "지금 접수할 수 있는 단지 3곳"과 그 이름·마감일 |
| 2. 오른쪽 `최근 변경`의 64자리 해시 `official_popup_hash 4017668b… → 59fded…` ×3 (화면 오른쪽 절반을 차지) | 2. TOP 단지 카드의 "얼마(현재 구매가)·언제 팔 수 있나(전매 종료)·주변 대비(가격 갭)" |
| 3. TOP 카드의 `종합 5.50`, `+10% 확률 53%`, `rerank 변화(이전 run 대비) 0.51` | 3. 이 순위가 무엇을 기준으로 한 상대 비교인지 한 줄 |

차이: 첫 화면이 "무엇을 할 수 있나"가 아니라 "시스템이 무엇을 셌나"로 시작한다. 큰 글씨 5개 중 초보에게 의미 있는 것은 `접수 가능 3` 하나뿐이고, 그것도 누르면 단지 목록이 아니라 출처 패널이 열린다.

- 같은 무게 요소: 지표 카드 5 + TOP 카드 3 + 변경 항목 3 = **11개**가 같은 테두리·같은 글씨 크기.
- 숫자 148개(해시 조각 포함), 배지 31개(라벨 배지 19).
- **레이아웃 결함**: 미분양 카드의 라벨 배지 문구 `확인됨(인천 검단구 737·인천 서해구 0·인천 영종구 1578·…·인천 강화군 0 합)`이 한 줄로 카드 밖으로 넘쳐 옆 카드(입주 피크·데이터 신선도)를 덮고 페이지 전체가 가로로 1,603px가 된다(REA 캡처 하단에 가로 스크롤바 보임). 모바일도 레이아웃 폭이 1,038px로 늘어난다.
- `통합 TOP 5` 제목인데 카드는 3개다(판정 대상이 6개뿐, 채점 3개). 왜 3개인지 설명이 없다.
- 설명 없는 용어: `판정 대상`, `추정(집계)`, `추정(집계(이 스냅샷 접수 행))`(괄호 이중), `입주 피크`, `데이터 신선도`, `실패 소스 0 · 지연 소스 0`, `종합`, `+10% 확률`(목표 시점이 카드에 없음 — 상세 사다리 탭에서야 "입주+1년 · 2030 하반기"), `rerank 변화(이전 run 대비)`, `추정(판정기 noul)`, `렌더 캡처`(`접수 가능 · 렌더 캡처`), `재판정 대상`, `official_popup_hash`, `준공 후`(미분양), `가중치 +10% 확률 0.35 · 판정기 순위 0.20 · 가격 갭 0.15 · 벤치마크 0.10 · 공급 0.10 · 유동성 0.10`.
- 출처·라벨이 본문을 가리는 곳: 미분양 카드(위 넘침), `추정(집계(이 스냅샷 접수 행))`처럼 배지가 숫자보다 길다. 찾기 어려운 곳: TOP 카드 순위의 근거(종합 점수 분해 차트가 첫 화면 아래).
- 상태: `미분양 추이` 차트에 `확인 불가` + `확인됨` 배지가 동시에 붙어 있다(무엇이 불가인지 모름). 로딩 상태는 관찰 시간 안에 지나감.

### G2 단지 리스트 (`/complexes?scenario=base`) — ours-g2-complexes-desktop-rea, ours-g2-complexes-mobile, t300/t800/t1500

| 2. 표 행마다 4~5줄로 접힌 단지 이름(`시티오/씨엘 8/단지`)과 이름 옆 `확인됨` 배지 | 2. 현재 구매가(얼마) |

차이: 첫 뷰포트에 단지가 **3행**만 보인다(1행 높이 약 95~135px). 이름 열은 좁아 4~5줄로 접히고, `접수` 열은 반대로 약 300px 넓은데 배지 하나만 있다. 숫자 하나마다 `확인됨` 배지가 붙어 숫자 43개에 배지 35개.

- 같은 무게 요소: 필터 11칸(초기화 포함) + 열 머리 10개가 같은 크기 회색 글씨.
- 설명 없는 용어: `택지유형`, `전매 종료일(이전)`, `포함 분류`(`민간분양 아파트` / `포함 확정 · 접수 가능`), `판정 범위`(값: 판정 대상·참고·제외·미해결), `가격 갭`(부호 의미 — +8.1%가 "주변보다 8.1% 싸다"인지 반대인지 없음), `종합 점수`, `마지막 변경`(값이 `official_popup_hash`), `추정(산술)`, `확인 불가(미판정, 2026-10-14)`.
- 기본 정렬은 `종합 점수 ▼`. 101개 중 점수 있는 단지는 3개라 나머지 98개는 `확인 불가(미판정)`로 정렬된다(API 표본 50개 중 판정 범위: 참고 35·제외 7·판정 대상 6·미해결 2, 접수: 확인 불가 42·가능 3·미정 3·불가 2).
- 접수 열 값 `접수 확인 불가(판정 미해결, 2026-10-14)` 같은 긴 사유가 배지로 들어가 행 높이를 키운다.
- 표가 자기 세로 스크롤을 가진다(페이지 스크롤 안에 표 스크롤 — REA 캡처 오른쪽에 스크롤바 2개). 하단 고정 `비교 트레이`가 표 마지막 보이는 행을 덮는다.
- 모바일(`ours-g2-complexes-mobile`): 필터 폼이 첫 화면의 약 2/3(10칸 2열)를 차지하고, 표는 `단지 · 생활권 · 접수` 3열만 보인다. 첫 화면 숫자 4개 — **가격·전매·점수가 하나도 안 보인다**. 카드형 전환 없음.
- **G2 초기 로드 흔들림(사용자 보고, 다른 에이전트 수정 중 — 기록만)**: 
  - t=300ms(`ours-g2-complexes-desktop-t300`): 헤더 `지역 없음` / `스냅샷 없음`, 상황 토글 없음, 필터 10칸이 **1줄**(판정 범위가 첫 줄 끝), 본문 `불러오는 중...`, 비교 트레이가 y≈330에 떠 있음.

  - t=1500ms: `인천`·`리비전 4`로 바뀌고 `CSV 내려받기` 버튼이 생기며 필터 칸 폭이 넓어져 `판정 범위`가 **2줄째로 내려감** → 필터 패널 높이 +20px, 그 아래 `101 / 101개`·`열 선택`·표가 한꺼번에 들어오고 비교 트레이가 y≈330 → 화면 하단(y≈837)으로 이동.
  - 측정: 누적 레이아웃 이동(CLS) 데스크톱 **0.080**(1,128ms에 0.0797 한 번에 발생), 모바일 0.050(1,172ms). 다른 화면은 0~0.009.

| # | 초보의 질문(순서대로) | 지금 답이 있는 곳 | 클릭 | 이해도 | 막히는 지점 |
|---|---|---|---|---|---|
| Q1 | **지금 넣을 수 있나?** | G1 지표 `접수 가능 3`(숫자만, 누르면 출처 패널) → G2 `접수` 열·필터(1클릭) → G3 단지명 옆 `접수 가능 · 렌더 캡처`(2클릭) | 1~2 | △ | 접수 **기간·마감일이 어디에도 없다**(원문 PDF에만). "접수 가능"이 일반 청약인지 무순위·선착순 계약인지 구분 표시 없음(32번은 수집 메모상 무순위/선착순 안내문 기반). 101곳 중 대부분 `확인 불가`. 청약 자격(통장·거주 요건)·특별공급 여부는 원문에만. 캘린더에도 접수일 없음 |

요약: 여섯 질문 중 혼자 끝까지 답할 수 있는 것은 없다(○ 0 · △ 3 · × 3). 답이 있는 경우도 2~3번째 탭이나 '출처 원문'·'데이터·운영' 같은 이름 아래에 있다. 홈·목록 첫 화면에서 가장 크게 보이는 것은 점수·확률·해시·라벨 배지다.

## 5. 가장 큰 이해 장애(우선순위, Phase 3 갭 표 입력용)

1. **초보 질문의 답이 엉뚱한 이름 아래 숨어 있다** — 거주의무·재당첨·규제(`출처 원문` 탭), 경쟁률(`잔여 이력` 탭), 중도금·계약 일정 캘린더(`데이터·운영` 맨 아래). evidence: ours-g3-detail-32-tab6-desktop, ours-g3-detail-32-tab2-desktop, ours-g7-ops-desktop-rea
2. **"얼마 필요하나"에 금액 답이 없다** — 계약금은 %와 1차 1,000만원만, 중도금 일정 1행, 잔금 확인 불가. 원문에 있는 금액은 열 이름 없는 숫자 줄로만 보임. evidence: ours-g3-detail-32-tab1-desktop, ours-g3-detail-32-provenance-desktop
3. **첫 화면이 시스템 지표 중심** — G1 큰 숫자 5개·해시 3줄·`rerank 변화(이전 run 대비)`, 비교표(G4)에 가격·전매가 없음. evidence: ours-g1-dashboard-desktop-rea, ours-g4-compare-desktop
4. **라벨 배지 과밀** — G3 첫 화면 숫자 89개에 라벨 배지 46개, G2 숫자 43개에 배지 35개. 모든 숫자가 같은 무게. 점선=출처 안내 없음. evidence: ours-g3-detail-32-desktop-rea, ours-g2-complexes-desktop-rea
5. **내부 용어·내부 ID 노출** — `noul/decide/rerank/classify`, `렌더 캡처`, `official_popup_hash`, `la_1~la_10` 범례, `complex_type · floor_sample_price_won`, `unlikely/likely`, "해석 실패". evidence: ours-g6-market-desktop-rea, ours-g3-detail-32-provenance-desktop, ours-g1-dashboard-desktop-rea
6. **표시값과 출처값 불일치처럼 보임** — 헤더 5억 9,850만원 → 출처 579,000,000(발코니 포함 여부). G3 `가격 갭` 두 값. G4 순위 1위 ≠ `decide 선택`. evidence: ours-g3-detail-32-provenance-desktop, ours-g3-detail-32-tab4-desktop, ours-g4-compare-desktop
7. **"+10% 확률"이 당첨 확률로 오해될 위험 + 가점 정보 전무**. evidence: ours-g1-dashboard-desktop-rea, ours-g3-detail-32-tab3-desktop
8. **레이아웃 결함** — G1 미분양 배지 넘침으로 가로 1,603px(모바일 1,038px), G2 이름 열 4~5줄 접힘·첫 화면 3행, 모바일 G2에 가격 열 없음, 상황 토글·메뉴 잘림, G2 초기 로드 흔들림(CLS 0.08). evidence: ours-g1-dashboard-desktop-rea, ours-g1-dashboard-mobile, ours-g2-complexes-mobile, ours-g2-complexes-desktop-t300/t800/t1500
9. **확인 불가 사유가 내부 실패 문구** — "판정 미해결", "해석 실패"가 초보에게 "앱 오류"로 읽힘. evidence: ours-g3-detail-1-desktop-rea
10. **보고서 산출물 없음** — G8 진단 관찰 불가. evidence: ours-g8-reports-desktop

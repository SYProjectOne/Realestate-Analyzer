## 부동산지인 — 수요/입주 대시보드 (https://aptgin.com/home/gin05/gin0501, 관찰일 2026-10-14, evidence_id aptgin-supply-rea-desktop · aptgin-supply-desktop-full)
- 첫 화면에서 가장 먼저 보이는 것 3개: ① 상단 고정 검색 바(지역 · 주택유형 · 초기화 · 검색 — 지역이 이 화면의 유일한 입력), ② 2단 탭(기본 / 플러스) 아래 서비스 홍보 배너(폭 전체), ③ 첫 차트 "기간별 수요/입주"(연도별 입주량 막대 + 수요량 선, 2000~2030).
- 정보 계층:
  - 1단(요약): 별도 결론 문장·KPI 카드 없음. 첫 차트(장기 입주량 vs 수요량)가 사실상의 요약 역할.
  - 2단(핵심 수치): 차트 4장을 위→아래로 쌓음 — 기간별 수요/입주 → 하위 지역별 수요/입주(연도별 막대 + 수요량 점) → 면적별 입주량 → 면적별 분양가격. 그 아래 면적별 표(입주 시기 × 면적대, 세대수·분양가).
  - 3단(상세): **지역별 수요/입주 표**(행 = 하위 지역, 열 = 연도마다 수요량·입주량·판정 라벨) → 범례 색상 기준 → 지역별 아파트(기간 지정 후 단지 목록, 처음엔 "지역을 선택해 주세요" 빈 상태 일러스트).
- 묶음 단위: 카드처럼 테두리 친 **차트 패널을 세로로 쌓는 대시보드**. 패널마다 제목 가운데·오른쪽 위에 "범례 전체 닫기 + 메뉴(내보내기)". 차트 다음에는 같은 데이터를 표로 다시 준다(차트→표 순서). 지역 막대 차트는 가로 스크롤바로 지역을 넘긴다.
- 숫자 표기: 차트 라벨은 "N.N만"(만 단위 소수 1자리), 축은 "25k/50k". 표는 천 단위 콤마 정수. 마우스를 올리면 툴팁에 연도별 정확한 값(콤마 정수)이 뜬다. 단위는 패널 오른쪽 위 출처 줄에 같이 씀("출처: … , 단위: 세대/만원").
- 상태·라벨 표현:
  - **수요 대비 입주 비율을 4단계 텍스트 라벨(부족/적정/초과/과잉)로 표 셀마다 붙이고, 표 바로 아래 "범례 색상 기준"에 각 라벨의 비율 구간(예: 80% 이하, 80~120% …)을 숫자로 명시**한다. 라벨은 색 칩 안에 글자가 들어 있어 색 없이도 읽힌다.
  - 출처·단위는 **각 차트/표 패널의 오른쪽 위 작은 회색 글씨**("출처: 자체수집(상시), 단위: 세대"). 미분양 화면은 "출처: 통계누리 / 기준일: YYYY-MM", 상세 검색은 "출처 / 최초제공일 / 기준일"까지 쓴다(aptgin-unsold-desktop).
  - 분양가 차트 아래에 "연면적 분양가격은 아파트만 제공" 같은 데이터 범위 각주.
- 필터·정렬: 지역·주택유형 2개(상단 고정). 지역별 아파트 표는 기준년월 범위(최대 3년) 지정. 범례 항목 클릭으로 계열 끄기.
- 용어 처리: 왼쪽 고정 아이콘 메뉴에 "용어설명"·"자료출처"가 상시 노출(어느 화면에서나 한 번에 닿음). 지역분석 표의 열 제목 옆 "?" 아이콘으로 지표 설명(시장강도·거래량 등). 홈의 자주 묻는 질문 첫 줄이 "수요량 산정 방법"·"시세와 시장강도 설명"이다 — 자체 지표의 산식 설명을 FAQ 맨 위에 둔다.
- 모바일에서 달라지는 것(aptgin-region-mobile): 왼쪽 아이콘 메뉴가 **하단 고정 아이콘 바**로 내려간다. 검색 바가 비어 보이는 띠로 바뀌고(입력이 숨음), 차트는 폭만 줄어 제목이 세로로 여러 줄 꺾인다(읽기 어려움). 표는 가로 스크롤.
- 우리에게 쓸 만한 패턴(우리 말로 한 줄씩):
  - 지역 공급 화면(G6)은 "장기 추이 차트 → 하위 지역 비교 차트 → 같은 데이터 표 → 단지 목록" 순서로 위에서 아래로 좁혀 간다.
  - 판정/구간 라벨을 표 셀에 텍스트로 붙이고, **표 바로 아래에 라벨별 숫자 구간(범례 기준)을 명시**한다 — 라벨의 근거가 한 화면 안에 있다. (우리는 라벨을 만들지 않고 API 라벨에 기준 설명만 붙인다.)
  - 출처·단위·기준일을 패널 오른쪽 위 한 줄로 붙인다(패널 단위 출처). 공식 통계 기반이면 "최초 제공일 / 기준일"까지.
  - 용어집·자료출처를 전역 고정 메뉴로 둬 어느 화면에서든 한 번에 닿게 한다.
  - 차트 막대 위에 축약 값(만 단위)을 직접 쓰고, 정확한 값은 툴팁·표로 연다.
  - 지역을 고르기 전에는 빈 상태 안내 한 줄 + 일러스트로 "무엇을 해야 하는지"를 알려 준다.
- 우리에게 맞지 않는 것과 이유:
  - 첫 화면 대부분을 차지하는 자사 서비스 홍보 배너(핵심 차트를 아래로 밀어냄).
  - 모든 차트 배경의 큰 워터마크 로고(숫자 판독 방해).
  - 4분면 버블 차트(지역분석 시장강도) — 축 의미를 모르면 초보자가 읽을 수 없다. 우리 페르소나에는 표·막대가 맞다.
  - 프리미엄(유료) 유도 링크가 상단·홈에 반복.

## 부동산지인 — 지역분석(시장강도) (https://aptgin.com/home/gin01/gin0101/loc/4159700000, 관찰일 2026-10-14, evidence_id aptgin-region-desktop · aptgin-region-desktop-full · aptgin-region-mobile)
- 첫 화면에서 가장 먼저 보이는 것 3개: ① 상단 지역 검색 바(선택된 지역명), ② 홍보 배너, ③ 지역명 제목 + "시장강도 / 가격" 2단 토글 + 기준월 이전·다음 버튼 + 4분면 버블 차트(하위 지역별 매매·전세 강도).
- 정보 계층: 1단 = 지역명 + 규제지역 텍스트(조정대상·투기과열) → 2단 = 하위 지역 비교 표(지역(단지수) · 시장강도 · 입주(올해) · 거래량 · 시세(매매/전세/전세율)), 최대 3개 지역 비교 담기 → 3단 = 멀티차트(주요지표·거래량·매물·시세·소득·경매 탭), 면적별·연차별 시장강도 표.
- 묶음 단위: 차트 패널 + 정렬 가능한 표 + 지표 탭. 비교는 행 체크박스로 담아 "지역 비교하기"(최대 3개).
- 숫자 표기: 가격은 "3.3㎡ / 1㎡" 단위 토글, "만 원(공급면적 기준)"이라고 기준 면적을 명시. 기준월은 YYYY-MM 드롭다운 + 이전/다음.
- 상태·라벨 표현: 시장강도 구간을 4개 숫자 구간 범례로 표기(색 + 구간 숫자). 상승/보합/하락은 색 점 + 글자 범례. 규제지역은 지역명 아래 텍스트.
- 필터·정렬: 기준월 이동, 단위 토글, 열 제목 정렬, 비교 담기(최대 3).
- 용어 처리: 열 제목 옆 "?" 툴팁(시장강도·거래량·지역(단지수)).
- 모바일에서 달라지는 것: 위 수요/입주와 같음(하단 아이콘 바, 차트 제목 줄바꿈, 버블이 겹쳐 판독 곤란).
- 우리에게 쓸 만한 패턴:
  - 기준월을 "이전 / 현재 / 다음" 3버튼으로 바꾸는 시점 이동(스냅샷 비교의 단순한 UI). 우리 D10-1(발행 스냅샷과 현재 값 분리)에 맞는다.
  - 가격 단위의 기준 면적(공급/전용)을 숫자 옆에 항상 써 준다.
  - 비교 담기 개수 상한을 미리 알려 준다("최대 N개").
- 우리에게 맞지 않는 것과 이유: 자체 합성 지표(시장강도)를 첫 화면 주인공으로 둔 것 — 우리는 점수를 새로 만들지 않는다. 4분면 차트는 초보자에게 해석 부담.

## 다방 — 홈 (https://www.dabangapp.com/, 관찰일 2026-10-14, evidence_id dabang-home-rea-desktop)

- 첫 화면에서 가장 먼저 보이는 것 3개: 중앙 큰 검색창("지역, 지하철, 대학, 단지명 또는 매물번호"), 매물 유형 카드 5장(원/투룸·아파트·주택/빌라·오피스텔·분양 — 제목 + 회색 한두 줄 설명 + 아이콘), 우측 광고 배너.
- 정보 계층: 1단 = "무엇을 찾나"(유형 카드), 2단 = 카드 설명 한 줄("전국의 모든 분양/입주 정보 확인 가능"), 3단 = AI 추천 매물 목록(해시태그 칩 필터).
- 묶음 단위: 입구 카드 격자. 카드 위에 "최근 방문" 말풍선으로 개인 맥락 표시.
- 숫자 표기: 해당 없음(매물 목록 제외).
- 상태·라벨: "새단장" 붉은 테두리 텍스트 배지.
- 우리에게 쓸 만한 패턴: 입구 카드에 "이 메뉴에서 무엇을 볼 수 있나"를 한 줄로 쓴다(우리 G1 → G2·G6 진입 카드).
- 맞지 않는 것: 대형 광고 배너, "AI가 대신 찾아봤어요" 추천형 문구.

## 다방 — 지도 > 분양 (https://www.dabangapp.com/map/sale-in-lots, 관찰일 2026-10-14, evidence_id dabang-salemap-rea-desktop)

- 첫 화면에서 가장 먼저 보이는 것 3개: (1) 좌측 "이 지역 분양 정보" 카드 목록, (2) 우측 지도 위 시군구별 단지 수 원형 칩("12 고양시 일산동구"), (3) 상단 필터 4개 드롭다운(건물유형·분양단계·분양일정·공급유형) + 초기화 아이콘.
- 정보 계층(카드 하나):
  - 1단: **상태 배지**(접수중 = 진한 색 채움, 접수마감 = 회색 채움, 분양예정·입주예정·입주모집 등 텍스트) + 바로 아래 **다음 일정 한 줄**("26.10.14 2순위 청약", "26.10.24 ~ 26.10.26 계약기간", "27.05월 모집공고", "29.07월 입주예정일") — 상태에 맞는 "다음에 일어날 일과 날짜"를 한 줄로.
  - 2단: 단지명(굵게, 2줄까지) → 주소(시군구 동까지) → 건물유형.
  - 3단: "분양가 6억1400"(대표가) → 회색 "333세대, 민간분양"(규모·공급유형).
- 묶음 단위: 사진 + 텍스트 가로 카드의 세로 목록, 지도는 행정구역 단위 개수 칩.
- 숫자 표기: 분양가는 "6억1400"(억 + 만 단위, '만' 생략), 날짜는 "26.10.14"(연 두 자리), 기간은 "~". 값이 없으면 "분양가 준비중".
- 상태·라벨 표현: 접수중/접수마감/분양예정/입주예정/입주모집을 텍스트 배지로, 색은 보조. 공공임대는 "분양가" 대신 "임대가" 라벨로 바꿔 쓴다(값의 성격을 라벨이 말해 줌).
- 필터·정렬: 4개 필터 모두 드롭다운(기본 전체), 필터 초기화 버튼 1개. 지도 이동 시 목록이 "이 지역"으로 갱신.
- 용어 처리: 단계명은 그대로(특별공급·1순위·2순위·계약기간). 설명 없음.
- 모바일에서 달라지는 것: 아래 모바일 항목 참조.
- 우리에게 쓸 만한 패턴(우리 말로):
  - 단지 카드 맨 위 = **상태 배지 + "다음 일정(날짜 + 단계명)" 한 줄**. 초보자의 "지금 넣을 수 있나 / 언제 뭐가 있나"에 카드 첫 줄이 답한다. 우리 G2 카드·행의 1단 후보(날짜는 D7대로 D± 병기).
  - 대표가 한 개 + 회색 보조 줄(세대수, 공급유형). 카드의 수치는 2개 이내.
  - 값의 성격이 다르면 라벨 자체를 바꾼다(분양가/임대가) — 우리 라벨 체계(공식·추정)와 같은 발상.
  - 값 없음 = "준비중" 문장(우리 "확인 불가(사유)").
- 맞지 않는 것: 사진 썸네일 의존(우리 데이터엔 이미지가 없음), "핫한" 류 문구(아래 테마 참조).

## 다방 — 분양 탭 메인 (https://www.dabangapp.com/sale-in-lots, 관찰일 2026-10-14, evidence_id dabang-saletab-rea-desktop)

- 첫 화면에서 가장 먼저 보이는 것 3개: 하위 메뉴(분양정보·테마분양·분양일정·분양가이드·브랜드관), "테마분양" 카드 3장(테마 제목 + 조건 태그 칩), 진한 배경의 "분양일정" 섹션.
- 정보 계층:
  - 테마분양: 카드 = 사용자 상황별 묶음("지금 청약 가능한 단지" / "청약통장·지역요건 없이 가능한 무순위·임의공급" / 고급 단지). 각 카드 아래 조건 태그(특별공급·1순위·2순위 / 통장 불필요·지역요건 없음 / …).
  - 분양일정: 왼쪽 "Today 10월 14일 수요일" + 단계별 건수(접수 8 · 공고 0 · 발표 5 · 계약 3) → 가운데 오늘 항목 목록("접수 [2순위 청약] 지역 단지명 (~10/14)") → 오른쪽 이후 날짜별 건수("10월 15일 목요일 10건 >").
  - 분양가이드: "알기쉬운 주택 청약 절차"(1. 통장 가입 → 2. 주택 찾기 → 3. 내 자격과 순위 확인), "분양 용어 알아보기"(공고문·대출·주택·건축물 용어), "자주하는 분양질문"(가점제란? 1순위 조건? 생애최초 특공이란?) + 청약가점 확인·입주자격 진단 링크.
  - 분양 정보 표: 열 = 단계 / 건물유형 / 공급유형 / 단지명·위치 / 분양가 / 세대수 / 전용면적.
- 묶음 단위: 테마 카드, 일정 3열(오늘 요약·오늘 목록·다가오는 날짜), 가이드 3열 목록, 정보 표.
- 숫자 표기: 일정 마감 "(~10/14)", 날짜에 요일, 건수 "10건".
- 상태·라벨 표현: 일정 행 맨 앞 단계 텍스트(접수/발표/계약) + 대괄호 세부 단계("[2순위 청약]", "[임의공급]").
- 필터·정렬: 일정은 오늘 → 다음 날짜 순, "모두보기".
- 용어 처리: **분양가이드 블록을 분양 메인 안에 둔다** — 절차 3단계, 용어 묶음, 질문형 FAQ(가점제·1순위·특별공급). 초보자 용어 해결 경로가 분양 화면에서 한 번에 닿는다.
- 우리에게 쓸 만한 패턴:
  - 일정 블록 = "오늘(요일) + 단계별 건수" → "오늘 항목(마감일 괄호)" → "다음 날짜별 건수". 우리 G1 대시보드 "이번 주 일정" 블록 구조 후보.
  - 상황별 묶음("지금 신청 가능", "통장 없이 가능")을 조건 태그로 설명 — 단, 우리는 묶음 기준을 판정기·공고 데이터에서만 가져와야 함.
  - 청약 절차 3단계 + 질문형 FAQ를 목록·상세 화면 옆에 상시 링크(우리 용어집 진입점).
- 맞지 않는 것과 이유: 테마 제목의 "핫한", "줍줍", "모두가 원하는" 등 권유 수식어(판단을 만들지 않는다는 규칙 위반 소지). 브랜드관(광고). "Theme 01" 같은 영문 장식.

## 다방 — 모바일 웹 (https://www.dabangapp.com/mobile/map/sale-in-lots 시도, 관찰일 2026-10-14, evidence_id dabang-salemap-mobile)

- 모바일 UA로 분양 지도/분양 탭에 들어가면 **원/투룸 지도로 리다이렉트**되고, 하단 시트로 "앱에서 보세요 / 모바일 웹으로 볼게요"가 뜬다. 모바일 웹에는 분양 화면이 없다(앱 전용).
- 관찰된 모바일 공통 패턴(원/투룸 필터 시트, 접근성 트리): 전체 화면 "전체필터" 시트 — 섹션 제목(거래유형·가격·방크기·사용승인일·층수·방구조·추가필터) + 각 섹션에 "중복선택 가능" 보조문 + 체크박스/라디오 칩, 하단 고정 "적용하기", 상단 "초기화". 범위 슬라이더 값은 "최소 ~ 최대 / 무제한" 문장.
- 우리에게 쓸 만한 패턴: 모바일 필터는 하나의 전체 화면 시트에 섹션별로 쌓고, 섹션마다 단일/복수 선택 여부를 보조문으로 적고, 초기화·적용을 고정한다(우리 모바일은 읽기 전용이지만 G2 필터 보기 상태에는 적용 가능).
- 맞지 않는 것: 앱 설치 유도 시트.

## robots.txt 확인 결과 (관찰 후 확인 — 사후 고지)

- 2026-10-14 관찰을 마친 뒤 robots.txt를 확인했다. 다방은 모든 UA에 대해 `/sale-in-lots`, `/mobile`, `/complex`, `/room` 등을 **Disallow**한다(`/map/...`과 `/`는 허용).
- 따라서 `dabang-saletab-rea-desktop`(/sale-in-lots)와 `dabang-salemap-mobile`(/mobile/… 리다이렉트)은 robots 비허용 경로를 사람 관찰용 브라우저로 1회씩 연 것이다. 크롤링·반복 접근은 하지 않았지만, AGENTS 규칙 18(robots 준수)에 비추어 **Phase 3 종합에서 이 두 evidence는 근거로 쓰지 않거나 CEO 판단을 받는다**. 허용 경로 근거는 `dabang-home-rea-desktop`, `dabang-salemap-rea-desktop`(/map/sale-in-lots)이다.
- 분양 상세(`/complex` 계열로 추정)는 robots 비허용이라 추가 시도하지 않는다.

## 사이트 요약 (Phase 3 입력)

- 반복 패턴 후보: 상태 텍스트 배지 + 다음 일정 한 줄 / 일정 "오늘 + 단계별 건수 + 다음 날짜" / 값 없음 "준비중" / 날짜 요일 병기.
- 새 패턴: 값 성격에 따라 라벨 교체(분양가↔임대가) / 분양 화면 안 분양가이드(절차 3단계·질문형 FAQ) / 모바일 전체필터 시트 "중복선택 가능" 보조문.
- 관찰 불가: 분양 단지 상세(목록 카드에 공개 URL이 접근성 트리에 노출되지 않고, 클릭 자동화 금지), 모바일 웹 분양 화면(모바일 UA는 원/투룸 지도로 리다이렉트 — 앱 전용).

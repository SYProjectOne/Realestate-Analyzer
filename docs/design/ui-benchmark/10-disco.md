- 정보 계층:
  - 1단(요약): 주소 + 건물 한 줄 요약(이름·용도지역·준공·세대·층).

  - 3단(상세): "거래내역 (41건)" + 칩(총액 / 공급면적당 단가 / 전용면적당 단가) → 표(거래일 · 거래금액 · 동/층/호(마스킹) · 등기 여부 배지 · 상세 >) 5행 + "더보기 (1/9)" → "실거래가 그래프"(3년간/1년간/전체 토글, 계열별 최신 시점 괄호 표기 "매매 (2026.02)", "전세 (2026.01)", 전세가율 %) → 주변 유사거래(조건 해시태그: 유형·면적대·최근 3개월·1km) → 경매 정보 → 토지 정보(키-값) → 개별공시지가(기준 연월 + 값, 이력 표 5/10/20건 보기 + 페이지) → 건물 정보(건축물대장 선택 캐러셀 + 표제부 키-값).

## Domain — 신축 홈 (https://www.domain.com.au/new-homes, 관찰일 2026-10-14, evidence_id domain-newhomes-desktop)

- 첫 화면에서 가장 먼저 보이는 것 3개: (1) 큰 사진 배경 위 한 줄 표어, (2) 거래 유형 탭 7개(매매, 임대, 토지+주택, **신축**(선택됨), 매각 완료, 은퇴 주거, 농촌), (3) "지역 또는 프로젝트 이름" 검색창 + 필터 + 큰 검색 버튼.
- 정보 계층: 1단 거래 유형 탭 + 검색 → 2단 제휴 광고 배너 → 3단 추천 주택 카드 캐러셀.
- 묶음 단위: 탭(거래 유형), 카드 캐러셀.
- 숫자·상태·용어: 첫 화면에는 없다.
- 우리에게 쓸 만한 패턴: 검색창 하나가 "지역" 또는 "단지 이름"을 모두 받는다. 우리 G2 검색에 단지명 검색을 함께 둔다.
- 맞지 않는 것: TV 프로그램 제휴 배너, "꿈의 집" 류 추천 캐러셀.

## Domain — 신축 아파트 목록 (https://www.domain.com.au/new-homes/north-sydney-nsw-2060/new-apartments/, 관찰일 2026-10-14, evidence_id domain-apartments-desktop)

- 첫 화면에서 가장 먼저 보이는 것 3개(이 탭은 열릴 때 이미 아래로 스크롤된 상태였다): (1) 오른쪽 절반의 지도(녹색 점 + 여러 단지가 겹치면 숫자 원), (2) 왼쪽 카드 열, (3) 상단 필터 줄(검색, 필터 아이콘, 가격, 방, "아파트·분양 예정"(선택됨)).
- 정보 계층:
  - 1단: 결과 수(제목 "○○개 신축·분양 예정 아파트").
  - 2단: 카드가 두 종류로 섞여 있다. **프로젝트 카드** = 단지 브랜드 띠 / 단지명(제목) / 주소 / "가격 문의" 또는 가격 / 방·욕실(최소 구성). **세대 카드** = 사진 / 신축·견학 일정 배지("오늘 12시 견학") / "판매 중 – 가격 문의" / 주소 / 방·욕실·주차 / 유형 라벨(신축 아파트·분양 예정) / 담당 중개인.
  - 3단: 사진 슬라이드(○/○), 찜, 알림 만들기.
- 묶음 단위: 카드 목록 + 지도(겹친 점은 숫자 원으로 묶음).
- 숫자 표기: 가격이 없으면 "가격 문의"를 가격 자리에 쓴다. 방·욕실·주차는 아이콘 + 숫자. 값이 없는 칸은 "−".
- 상태·라벨 표현: 판매 상태("판매 중")와 가격 정책("문의")을 한 줄로 합친다. 견학 일정은 날짜·시각 배지.
- 필터·정렬: 유형 필터(아파트·분양 예정)가 강조 칩으로 켜져 있다.
- 용어 처리: 없음.
- 모바일: 관찰 못 함.
- 우리에게 쓸 만한 패턴:
  - **단지(프로젝트) 카드와 세대 카드를 모양으로 구분**한다. 우리 G2는 단지 카드만 쓰되, 공급 유형(특별·일반)은 단지 카드 안의 하위 줄로 둔다.
  - 가격 자리를 비우지 않고 상태 문구("가격 문의")를 넣는다. 우리는 "확인 불가(분양가 미공고)".
  - 지도에서 겹친 단지를 숫자 원으로 묶는다(우리 지도 화면이 생기면 참고).
- 맞지 않는 것과 이유: 담당 중개인 이름·사진 노출, 유료 브랜드 띠.

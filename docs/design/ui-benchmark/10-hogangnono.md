# 10 — 호갱노노 (hogangnono.com) — 관찰 불가(robots)

- 확인일: 2026-10-14 · 확인자: Tier 1 서브에이전트(공공·시세 6곳 담당)
- 판정: **관찰 불가(robots)**. 관찰 노트·패턴 없음.
- 사유: `https://hogangnono.com/robots.txt` 는 이름을 적은 검색엔진 UA 목록에만 일부 경로를 허용하고, **`User-agent: *` 에 `Disallow: /`** 를 둔다. 파일 머리에 "명시적 서면 허락 없는 크롤링 금지" 고지도 있다. AI 에이전트 UA(ClaudeBot 등)는 허용 목록에 없으므로 `*` 규칙을 따른다 → 전 경로 금지. REA로 열지 않았다.
- 제외한 증거: 이 규칙이 내려오기 전(같은 날) Playwright로 홈 1페이지를 한 번 캡처했다 — `hogangnono-home-desktop`, `hogangnono-home-mobile` 와 그 접근성 텍스트(본문이 거의 비어 있었음). **이 증거는 제외(excluded)** 하며 패턴 근거로 쓰지 않는다. 파일은 저장소 밖 `C:\tmp\ui-bench\shots\` 에만 있다.
- 영향: 메타 프롬프트 §3-1이 "국내 사용자 습관"의 예로 든 사이트라, 단지 카드 밀도·시세 차트·상세 패널 계층은 다른 허용 사이트(KB·네이버 등 다른 서브에이전트 담당 — robots 결과에 따라)에서 확인해야 한다. 필요하면 사람이 직접 보고 메모해 보완한다.

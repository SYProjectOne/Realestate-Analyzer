## KB부동산 — 단지 상세·시세 (https://kbland.kr/c/2274, 관찰일 2026-10-14, evidence_id kbland-danji-rea-desktop · kbland-danji-rea-mobile)
- 첫 화면에서 가장 먼저 보이는 것 3개(크기·위치 순):
  1. 왼쪽 패널 상단의 단지 사진 슬라이드(패널 폭 전체, 높이 약 1/4) — 시각적 무게가 가장 크다.
  2. 사진 바로 아래 거래 유형별 매물 수 줄(매매 N · 전세 N · 월세 N · 동별매물) — 숫자만 강조색.
  3. 가운데 정렬 단지명(큰 글씨) + 한 줄 요약(유형·세대수·준공연도(연차)·공급면적 범위·규제지역·용적률/건폐율·도로명주소).
  — 정작 시세(가격)는 첫 화면에 없다. 광고 배너 1장과 탭 줄(시세·실거래가·타입·예산·금융상담·기본정보·주변시설…)을 지나야 나온다.
- 정보 계층:
  - 1단(요약): 단지 정체성 한 덩어리(이름 + 규모·연차·규제 한 줄). 결론·평가 문장은 없다.
  - 2단(핵심 수치): **시세 카드** — 거래 유형(매매/전세/월세)마다 한 블록. 블록 안 순서가 고정이다: 기준 시세(대표값) + 기준일 → 상위 평균 → 하위 평균 → 최근 실거래가(날짜·층) → 매물 평균가(없으면 "-"). 블록 하단에 "제공 주체 · 단위(만원)" 한 줄.
  - 3단(상세): 과거 시세 보기·시세 다운로드 버튼, 시세 조사에 참여한 중개업소 2곳, 시세/실거래 그래프(기간 전체·5년·3년·1년, 계열 토글), 타입별 카드(공급/전용·방/욕실·전용률·관리비), 기본정보 정의 목록(사용승인일·주소 복사·세대/동·주차·층·난방·건설사·관리사무소), 주변시설(학군·지하철·병원…).
- 묶음 단위:
  - 패널 안 **가로 탭**(앵커형: 누르면 같은 페이지의 해당 구획으로 이동)이 상세 전체의 뼈대. 탭 순서 = 시세 → 실거래 → 타입 → 예산 → 금융 → 기본정보 → 주변 → 커뮤니티.
  - 거래 유형(매매 / 전·월세)은 탭 안의 2버튼 토글, 면적은 오른쪽 드롭다운(기본 = 가장 작은 주력 평형).
  - 그래프 아래 "그 달 값" 요약 표(시세·건수)가 붙는다 — 차트의 커서 위치 값을 표로 되풀이.
  - 지도는 오른쪽 전체 면적을 차지하고 상세는 왼쪽 고정 패널(폭 약 1/3)에 뜬다.
- 숫자 표기:
  - 가격은 "N억 N,NNN만" 한글 단위, 패널 하단에 "단위(만원)" 명시. 지도 마커는 "NN.N억"(소수 1자리)로 축약.
  - **범위 표현은 "대표값 하나 + 상·하위 평균 두 줄"**이다. 범위 한 줄(최소~최대)로 합치지 않고 세 행으로 나눠 대표값을 가장 크게 둔다.
  - 기준일은 대표값 옆에 짧은 날짜('YY.MM.DD)로 붙인다. 실거래는 날짜 + 층을 함께 쓴다.
  - 매매-전세 차이를 그래프 위에 금액과 비율(%)로 같이 보여준다(갭).
  - 비교 기준: 대표값 vs 최근 실거래가 vs 매물 평균가 3종을 같은 블록에 나란히 둬서 사용자가 스스로 비교하게 한다(차이를 계산해 문장으로 만들지 않음).
- 상태·라벨 표현:
  - 출처는 **수치 블록 맨 아래 한 줄**("어디서 제공 · 단위")로 표기. 시세 이용 안내(신뢰 기준 설명)와 시세 의견 등록은 페이지 맨 아래 버튼으로 따로 있다.
  - 값이 없으면 "-" 또는 "시세없음" 텍스트(빈칸으로 두지 않음). 거래 건수 0은 "(0건)"으로 명시.
  - 규제지역(투기과열지구 등)은 단지 요약 줄에 색 글씨 텍스트로 붙는다(배지 아님).
  - 시세 조사 참여 중개업소에 "시세조사" 표시를 붙여 숫자의 출처가 "누가 조사했나"까지 이어진다.
- 필터·정렬: 거래 유형 2버튼, 면적 드롭다운, 그래프 기간 4버튼, 계열 토글 3개. 기본값은 매매·주력 소형 평형·전체 기간.
- 용어 처리: 공급/전용 면적은 토글 버튼으로 전환(설명 없음), 전용률·용적률·건폐율은 설명 없이 쓴다. 홈 화면에는 용어 해설 글(예: 분양가 제도 뜻)이 콘텐츠 카드로 섞여 있다(kbland-home-desktop).
- 모바일에서 달라지는 것: 관찰 창(약 750px)에서는 데스크톱 레이아웃이 그대로 줄어들었다(지도+왼쪽 패널 유지, 배너 폭만 축소). 420px 에뮬레이션(kbland-home-mobile)에서는 지도가 사라지고 홈이 세로 카드 피드가 되며, 화면 하단 절반을 분양 광고 시트가 덮는다.
- 우리에게 쓸 만한 패턴(우리 말로 한 줄씩):
  - 가격은 "대표값 크게 + 위·아래 범위 두 줄 + 기준일"로 3행 구성한다. 범위를 한 줄 "A~B"로 뭉치면 대표값이 묻힌다.
  - 대표값 바로 아래에 "최근 실제 거래가(날짜·층)"를 같은 블록에 둬서, 추정치와 실제값을 사용자가 한눈에 비교하게 한다(차이 판단은 하지 않는다).
  - 수치 블록마다 맨 아래 한 줄로 "출처 · 단위"를 붙인다(블록 단위 출처). 신뢰 기준 설명은 별도 링크로 한 번에 닿게.
  - 값이 없을 때 빈칸 대신 "-"/"없음"과 건수 "(0건)"을 명시한다 — 우리 "확인 불가(사유)"와 같은 방향.
  - 상세 페이지 뼈대는 앵커형 가로 탭(가격 → 거래 → 평형 → 자금 → 기본정보 → 주변) 순서가 국내 사용자에게 익숙하다.
  - 차트 아래에 커서 위치 값을 표로 되풀이한다(차트↔표 병치).
- 우리에게 맞지 않는 것과 이유:
  - 첫 화면 상단을 사진 슬라이드와 광고 배너가 차지해 핵심 가격이 스크롤 아래로 밀린다(우리 G3는 핵심 수치가 첫 화면에 있어야 한다).
  - 대출 상품·금융 상담·게임/포인트 같은 자사 상품 유도 구획.
  - 홈 화면의 "어제 가장 많이 오른 단지" 같은 등락 순위(투자 자극형, 판정기 결과가 아님).
  - 마커 클릭 시 로그인 모달(kbland-danji-desktop) — 공개 정보 앞에 로그인 벽.

## KB부동산 — 분양 탭(분양일정 목록) (https://kbland.kr/selot, 관찰일 2026-10-14, evidence_id kbland-bunyang-desktop · kbland-bunyang-desktop-full)
- 첫 화면에서 가장 먼저 보이는 것 3개: ① 패널 제목 "분양일정 | 결과조회" 2단 탭 + 분양/임대 토글, ② 지역 칩 가로 스크롤(전국·시도), ③ 큰 사진 카드 2장(인기 단지, 사진 위에 단지명·주소·민간/공공·총/일반분양 세대수).
- 정보 계층: 1단 = 인기·광고성 사진 카드 → 2단 = "청약 접수·예정" 목록(총 N개 · 최신순) → 3단 = 자금 준비(청약통장) 안내, 공유 버튼.
- 묶음 단위: 목록은 카드 리스트. 카드 한 장 = [상태 줄] + 단지명(굵게) + 주소 + "민간/공공 · 총 N세대(일반분양 N세대)" + 관심 버튼(관심 수).
- 숫자 표기: 세대수는 "총 N세대(일반분양 N세대)"로 전체와 실제 청약 대상 물량을 한 줄에 같이 쓴다. 입주 시점은 "YY.MM".
- 상태·라벨 표현: 카드 맨 위 상태 줄에 **[접수 단계] + [순위] + [오늘 표시] + 날짜**를 텍스트 배지로 붙인다(예: 1순위 접수가 오늘인지). "인기"는 별도 배지. 상태가 색이 아니라 글자로 읽힌다.
- 필터·정렬: 상태·유형 칩(전체·특별공급·1순위·2순위·무순위·추첨제·분양예정·수시모집) 8개 가로 줄, 기본 = 전체, 정렬 기본 = 최신순, 처음 5장만 보여주고 "더보기".
- 용어 처리: 특별공급·무순위·추첨제를 설명 없이 필터 칩 이름으로 쓴다.
- 모바일에서 달라지는 것: 관찰 못 함(420px 에뮬레이션은 홈만 찍었다).
- 우리에게 쓸 만한 패턴:
  - 카드 첫 줄을 "지금 어느 단계인가 + 오늘인가"의 텍스트 상태 줄로 시작한다(G2). 우리 D± 표기와 결합하기 좋다.
  - 세대수를 "전체(청약 대상)" 형태로 한 줄에 묶어, 초보자가 "실제로 넣을 수 있는 물량"을 바로 보게 한다.
  - 상태 필터를 칩 한 줄로, 기본 전체 + 최신순 + 처음 몇 개만 노출.
- 우리에게 맞지 않는 것과 이유: 인기 단지 사진 카드(광고 성격, 선정 근거 없음), 하단 분양 광고 회전 배너(시행사 문구 "마감임박·선착순" 등 판촉 문구), 게임·별 적립 구획.

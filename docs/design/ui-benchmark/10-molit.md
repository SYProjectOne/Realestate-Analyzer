## 실거래가 공개시스템 — 홈 (https://rt.molit.go.kr/, 관찰일 2026-10-14, evidence_id molit-home-desktop · molit-home-mobile)
- 첫 화면에서 가장 먼저 보이는 것 3개: ① 왼쪽 큰 제목(서비스 이름 4줄), ② 오른쪽 제도 안내 영상, ③ 상단 가로 메뉴(부동산 유형 8개 + 자료제공).
- 정보 계층: 1단 = 서비스 이름 + "쉽게 조회" 한 문장 → 2단 = 유형별 아이콘 입구 8개(아파트·연립·단독·오피스텔·토지·분양/입주권·상업·공장) → 3단 = 공지·FAQ(공개 데이터 범위, 통계와 다른 점), 콜센터·관련 기관 링크.
- 묶음 단위: 유형 아이콘 그리드, FAQ 리스트(날짜 붙음).
- 상태·라벨 표현: FAQ 첫머리가 "공개 데이터는 무엇을 포함하나", "주택거래통계와 다른 점과 활용 주의사항" — 데이터의 범위와 한계를 FAQ 최상단에 둔다.
- 모바일에서 달라지는 것: 상단 메뉴가 햄버거로 접히고, 첫 화면 전체를 제목 블록이 차지한다(유형 입구는 스크롤 아래).
- 우리에게 쓸 만한 패턴: 데이터 범위·한계 설명("무엇이 포함되고 무엇이 빠지나")을 FAQ 맨 위에 둔다.
- 우리에게 맞지 않는 것과 이유: 첫 화면을 다 차지하는 대형 제목·영상(행동 정보 없음).

## 실거래가 공개시스템 — 아파트 GIS 지도 (https://rt.molit.go.kr/pt/gis/gis.do?srhThingSecd=A, 관찰일 2026-10-14, evidence_id molit-gis-rea-desktop · molit-gis-mobile)
- 첫 화면에서 가장 먼저 보이는 것 3개: ① 화면 전체 지도(단지 아이콘 마커 + 묶음 원 숫자), ② 왼쪽 위 조건 칩 줄(연도 · 주소 구분 · 동 · 단지명 · 검색 아이콘), ③ 화면 맨 아래 한 줄 고지(지도에 안 보이는 단지는 검색창 이용 · **법적 효력 없음, 참고용**).
- 정보 계층: 1단 = 지도 + 조건 칩 → 2단 = 마커 선택 시 단지 결과(관찰 불가) → 3단 = 위성·거리뷰·규제지역 레이어 토글.
- 묶음 단위: 지도 단일 화면. 조건은 버튼처럼 보이는 칩(누르면 선택 목록).
- 숫자 표기: 지도 마커에 가격을 쓰지 않는다(단지 아이콘만). 가격은 선택한 뒤에만.
- 상태·라벨 표현: **"참고용·법적 효력 없음" 고지를 지도 아래 고정 띠로 상시 노출**. 규제지역은 레이어 토글.
- 필터·정렬: 연도(기본 = 올해), 주소 구분(지번/도로명), 동, 단지명.
- 용어 처리: 없음.
- 모바일에서 달라지는 것(molit-gis-mobile): 메뉴가 햄버거, 현재 유형을 "[아파트]" 텍스트로 머리에 표시, 조건 칩 줄은 유지, 고지 문구도 유지.
- 우리에게 쓸 만한 패턴:
  - 데이터 성격 고지(참고용·법적 효력 없음 — 우리로 치면 "투자 권유 아님 · 상대 비교")를 화면 하단 고정 한 줄로 늘 보이게 한다(D7 규칙과 같은 방향, 공공 사이트에서도 확인됨).
  - 조건(연도·지역·단지)을 칩 한 줄로 화면 위에 띄워, 지금 무엇을 보고 있는지 항상 보이게 한다.
- 우리에게 맞지 않는 것과 이유: 지도만으로 단지를 찾게 하는 구조(초보자는 어디를 눌러야 할지 모름), 결과까지 클릭이 여러 번 필요.

## 실거래가 공개시스템 — 자료제공(조건별 내려받기) (https://rt.molit.go.kr/pt/xls/xls.do, 관찰일 2026-10-14, evidence_id molit-xls-desktop · molit-xls-desktop-full)
- 첫 화면에서 가장 먼저 보이는 것 3개: ① 큰 가운데 제목, ② **강조색 상자 안의 이용 유의사항 5줄**(법적 효력 없음·공식 통계는 신고일 기준 별도, 신고 변경·해제로 건수가 달라질 수 있음, **이 자료는 계약일 기준**(예시로 계약월·신고월 관계를 풀어 씀), 신고 기한 법 조항, 조회 범위 최대 1년), ③ 유형 탭 8개 + 매매/전월세 토글.
- 정보 계층: 1단 = 유의사항(데이터의 기준과 한계) → 2단 = 조건 폼(계약일자 범위·주소 구분·시도·시군구·읍면동·단지명·면적 구간·금액 범위) → 3단 = EXCEL / CSV 내려받기 버튼.
- 묶음 단위: 상자형 유의사항 + 2열 폼 + 오른쪽 아래 버튼 2개.
- 숫자 표기: 날짜 YYYY-MM-DD, 금액 입력 단위 "만원"을 입력칸 안내 글에 명시. 면적은 전용 구간 5개(60㎡ 이하 ~ 135㎡ 초과).
- 상태·라벨 표현: 결과가 없을 때의 동작(목록이 비어 제공되지 않음)을 미리 유의사항에 적어 둔다.
- 필터·정렬: 기본 계약일 범위 = 오늘 기준 최근 1년, 나머지 "전체".
- 용어 처리: "계약일 기준"을 예시 한 줄로 풀어 줌(괄호 예시).
- 모바일에서 달라지는 것: 관찰 안 함(1페이지 1회 원칙, 데스크톱만).
- 우리에게 쓸 만한 패턴:
  - 원자료를 보여 주는 화면 맨 위에 **"이 숫자의 기준일 종류(계약일/신고일)와 집계 시점 차이"**를 예시 한 줄로 밝힌다. 우리 실거래·시세 수치의 "확인일"과 "거래일"을 구분 표기하는 근거.
  - 결과가 비는 조건을 미리 문장으로 알려 준다(빈 상태 사유 사전 고지).
  - 원자료 내려받기(CSV)를 화면 표와 별개로 제공 — 우리 보고서의 "표로 열기/원본 링크" 방향과 같다.
- 우리에게 맞지 않는 것과 이유: 결과 미리보기 없이 파일 내려받기만 있는 구조(초보자는 엑셀을 열어야 함).

## 실거래가 공개시스템 — 공개안내 (https://rt.molit.go.kr/pt/info/info.do, 관찰일 2026-10-14, evidence_id molit-info-desktop · molit-info-desktop-full)
- 첫 화면에서 가장 먼저 보이는 것 3개: ① 큰 제목 띠, ② 공개 목적 한 문단, ③ 테두리 상자 3개(매매 공개 대상 / 전월세 공개 대상 / 유의사항).
- 정보 계층: 1단 = 공개 목적 → 2단 = 공개 대상과 시작 시점(매매 2006년~, 분양/입주권 2007년~, 전월세 2021년~ 등, 시작 연월을 강조색) → 3단 = **실거래 공개(국토부) vs 거래현황통계(한국부동산원) 비교표**.
- 묶음 단위: 상자 3개 + 비교표 1개(행 = 활용목적·집계기준·관리범위·공개기준, 열 = 두 자료원). 표에 caption(표 설명)을 달아 접근성을 지킨다.
- 숫자 표기: 날짜는 "YYYY년 M월", 강조색.
- 상태·라벨 표현: 출처가 둘인 숫자가 서로 다를 수 있다는 사실을 **비교표로 미리 설명**(집계 기준이 계약일 vs 신고일, 공개 시점이 익일 vs 월말).
- 용어 처리: 표 형식으로 차이를 보여 줘 용어 정의를 대신함.
- 우리에게 쓸 만한 패턴:
  - 같은 지표가 출처마다 다를 수 있으면 "출처 A vs 출처 B" 비교표(목적·집계 기준·범위·공개 주기 4행)를 출처 설명 화면에 둔다 — 우리 "출처 상충"을 판정기가 판단하고, 화면은 출처별 기준 차이를 설명하는 용도.
  - 데이터마다 "언제부터 공개되는 자료인가(시작 연월)"를 명시.
- 우리에게 맞지 않는 것과 이유: 없음(구조는 단순하고 공공 고지 성격).

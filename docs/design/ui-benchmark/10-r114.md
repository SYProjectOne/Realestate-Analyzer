## R114 — 홈(지도) (https://www.r114.com/, 관찰일 2026-10-14, evidence_id r114-home-rea-desktop, r114-home-desktop)

- 첫 화면에서 가장 먼저 보이는 것 3개: (1) 화면 중앙 건설사 브랜드 광고 모달(오늘 하루 보지 않기/닫기), (2) 그 뒤 전체 화면 지도 위 단지 말풍선(가격 "억" + 평형 또는 "N개 단지" 묶음, 일부 평점 별), (3) 상단 중앙 검색창("어떤 단지나 지역 찾으세요?")과 실거래/시세 토글·단지 비교하기 버튼.
- 정보 계층: 1단 = 지도 말풍선의 대표가(억 단위, 소수 첫째 자리) + 평형, 2단 = 말풍선 클릭 시 패널(관찰 불가 — 클릭 금지), 3단 = 원문.
- 묶음 단위: 지도 + 말풍선. 같은 위치 여러 단지는 "N개 단지"로 묶는다. 분양 단지는 다른 색 말풍선("분양" 라벨)으로 구분.
- 숫자 표기: "28.5억 / 34평" — 억 단위 소수 첫째 자리, 평 단위.
- 상태·라벨 표현: 분양 단지 말풍선에 텍스트 "분양" 라벨(색 + 글자).
- 필터·정렬: 좌하단 옵션·필터·지도 버튼(세로 스택), 상단 주거용/상업용 토글.
- 용어 처리: 관찰 범위에서 없음.
- 모바일: 범위 밖.
- 우리에게 쓸 만한 패턴: 지도/목록 마커에서 분양 단지를 색 + "분양" 글자로 동시에 구분(D7 "라벨은 텍스트 배지"와 일치).
- 맞지 않는 것: 진입 즉시 광고 모달(접근성 트리상 본문이 모달 뒤로 숨겨짐 — aria-modal로 모달 내용만 노출). 우리 앱엔 해당 없음.

## R114 — 분양 (https://www.r114.com/apply, 관찰일 2026-10-14, evidence_id r114-apply-rea-desktop)

- 첫 화면에서 가장 먼저 보이는 것 3개: (1) "시공사별 분양정보" 큰 사진 카드 가로 캐러셀(건설사명 소제목 + 단지명 + "최근 분양 현장" 링크), (2) "분양중인 단지" 섹션 제목 + 한 줄 안내문, (3) 단지 카드 가로 캐러셀(조감도 / 단지명 / 주소 / "모집공고 YYYY.MM.DD").
- 정보 계층:
  - 1단(요약): 섹션 안내문 "모집공고가 등록된 분양 단지를 모았어요. 카드를 누르면 AI 모집공고 요약을 확인할 수 있어요." — 이 목록이 무엇인지, 누르면 무엇이 나오는지를 한 문장으로 먼저 알려준다.
  - 2단: 카드 = 단지명(굵게) → 주소(회색, 1줄 말줄임) → "모집공고 날짜"(회색). 가격·경쟁률은 카드에 없다(카드 밀도 낮음).
  - 3단: 카드 클릭 → AI 모집공고 요약(모달/패널, 클릭 금지라 관찰 불가).
- 분양 캘린더(같은 페이지 아래쪽, 접근성 트리로 관찰):
  - 머리: "접수중 N" 카운트 + 오늘 접수 중인 단지 칩(유형 배지 "1순위/2순위" + 단지명 + 지역 · 세대수).
  - 월 달력: 날짜 칸마다 단지명 3개까지 + "+N건 더보기". 주(週) 단위로 "특공 N · 1순위 N · 2순위 N · 발표 N · 계약 N" 요약 칩을 따로 둔다.
  - 이벤트 카테고리 필터: 특별공급 / 1순위 / 2순위 / 발표 / 계약(토글 버튼 그룹).
- 묶음 단위: 가로 캐러셀 카드(분양중 단지), 월 달력(일정), 기사 목록(분양 뉴스, 날짜 포함).
- 숫자 표기: 세대수 "314세대", 날짜 "2026.10.08"(목록) / "2026. 4. 21."(기사) — 형식이 섹션마다 다름. D± 표기는 없음.
- 상태·라벨 표현: 단계명을 텍스트 배지로("1순위", "2순위", "특공", "발표", "계약"). 탭 "신규 분양 / 무순위"로 물량 종류 분리. 조감도가 없으면 "조감도 준비중" 대체 텍스트(빈 상태를 문장으로).
- 필터·정렬: 신규 분양(기본) / 무순위 탭. 정렬 기준 표시는 없으나 모집공고일 최신순으로 보임.
- 용어 처리: "무순위", "특공" 같은 줄임말을 설명 없이 사용. 대신 "AI 모집공고 요약"으로 공고문 해석을 대신 제공(판단이 아니라 요약).
- 모바일: 범위 밖.
- 우리에게 쓸 만한 패턴:
  - 목록 머리에 "이 목록은 무엇이고, 누르면 무엇이 나오는가"를 한 문장으로(우리 G2 머리 안내문).
  - 일정 캘린더: 날짜 칸은 3건 + "+N건 더보기", 주 단위 단계별 건수 요약 칩, 단계(특공·1순위·2순위·발표·계약) 필터 — 우리 G1 일정 블록/캘린더에 그대로 맞는 구조.
  - "오늘 접수 중" 카운트를 캘린더 위에 먼저 — 초보자의 "지금 넣을 수 있나?"에 바로 답.
  - 이미지/값이 없을 때 "○○ 준비중" 문장 대체(우리 "확인 불가(사유)"와 같은 방향).
- 맞지 않는 것: 시공사별 브랜드 캐러셀(광고성, 최상단을 차지), 캘린더 사이 배너 광고. 날짜 형식 불일치.

## R114 — 트렌드 / 부동산 위키 (https://www.r114.com/trends, 관찰일 2026-10-14, evidence_id r114-trends-rea-desktop)

- 첫 화면에서 가장 먼저 보이는 것 3개: (1) "부동산 위키" 제목 + 한 줄 소개("청약부터 세금, 대출, 정비사업까지 … 쉽고 깊이 있게"), (2) 10개 주제 카드 격자(아이콘 + 주제명 + 부제: 매매/전월세/금융/청약/세금/경매/제도/정비사업/상업용/생활정보), (3) 위키 글 목록(질문형 제목 + 한 줄 답 + 날짜) + 우측 "많이 본 트렌드 TOP3".
- 정보 계층:
  - 1단: 질문형 제목("최하층 우선배정 세대, 당첨에 더 유리할까?").
  - 2단: 바로 아래 회색 한 줄이 **답의 결론**("당첨 확률과 무관하며 … 동·호수를 정할 때만 적용됩니다"). 목록만 읽어도 답을 얻는다.
  - 3단: 본문(클릭).
- 묶음 단위: 주제 카드 격자(용어 사전 입구), 텍스트 목록(위키), 썸네일 목록(뉴스·칼럼), 카드뉴스 캐러셀, "Buy & Sell 리포트"(단지 하나를 골라 소개하는 기사).
- 숫자 표기: 날짜 "2026. 10. 8.".
- 상태·라벨 표현: 해당 없음.
- 필터·정렬: 주제 카드가 곧 필터. "위키 전체 보기", "전체 칼럼 보기" 링크.
- 용어 처리: **용어를 질문형 위키 항목으로 따로 만든다**(방공제, 계약갱신청구권 등). 칼럼 "1순위 청약지도(주간)"는 "이번 주 청약 단지 4곳 + 접수 일정 정리" 형식.
- 모바일: 범위 밖.
- 우리에게 쓸 만한 패턴:
  - 용어 설명을 "질문형 제목 + 결론 한 줄" 카드로 — 우리 용어집(전매제한·거주의무·중도금·가점제·특별공급) 항목 형식에 적합. 목록만 읽어도 답이 되게.
  - 보고서/요약 블록에서 "이번 주 일정 정리" 같은 기간 단위 묶음 제목.
- 맞지 않는 것: 칼럼·카드뉴스의 자극적 제목("로또", "무조건 직진" 등 추천·권유 문구) — 우리는 판정기 결과만 보여주므로 흉내 내지 않는다. Buy & Sell 리포트는 단지 추천 성격이라 제외.

## 사이트 요약 (Phase 3 입력)

- 반복 패턴 후보: 단계 텍스트 배지(특공·1순위·2순위·발표·계약) / 일정 캘린더 "N건 + 더보기" / 목록 머리 한 문장 안내 / 빈 이미지 "준비중" 문장.
- 새 패턴: 질문형 용어 항목 + 결론 한 줄(목록에서 바로 답) / 주 단위 단계별 건수 칩 / "오늘 접수중 N" 카운트.
- 관찰 불가: 단지 카드 클릭 시 열리는 "AI 모집공고 요약" 상세(카드가 링크가 아닌 버튼이라 공개 URL이 없음 — 클릭 자동화 금지로 관찰 불가). 홈 지도 단지 패널도 같은 사유.

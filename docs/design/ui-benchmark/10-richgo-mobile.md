## 리치고 모바일 — 홈 지도 (https://m.richgo.ai/, 관찰일 2026-10-14, evidence_id richgom-home-mobile, richgom-home-rea-mobile)

- 첫 화면에서 가장 먼저 보이는 것 3개(모바일): (1) 상단 앱 설치 배너(닫기 + "앱 다운로드"), (2) 지도 위 단지 말풍선 — "N평 / 호가 ○억 / 실 ○억" 3줄(라벨 글자 "호가", "실"로 값의 종류를 구분), (3) 하단 고정 한 줄 티커(순위 원 + "평형 · 단지명 / 현재가 > 예측가 / ○억 예상") + 하단 탭바(커뮤·지도·경매·메뉴).
- 정보 계층: 1단 = 말풍선 2가지 값(호가/실거래), 2단 = 하단 한 줄 요약(선택 단지), 3단 = 단지 상세(이동).
- 묶음 단위: 지도 + 오른쪽 세로 레이어 토글(미래·단지·오피·경매·중개·호재·학군·도구 — 켜진 것은 채운 색), 왼쪽 아래 지역 선택("서울 / 강남구 ▾"), "청약" 플로팅 버튼.
- 숫자 표기: "호가 33.9억 / 실 35.8억" — 억 소수 첫째 자리, 평형은 "평".
- 상태·라벨 표현: 값 앞 짧은 텍스트 라벨(호가·실·경매). 경매 말풍선은 테두리 다른 카드 + "저렴/비쌈" 문구.
- 필터·정렬: 상단 칩 한 줄(매매 ↕, 필터 아이콘, 가격 ▾, 평형 ▾) — 모바일에서는 필터를 칩으로 축약하고 상세는 시트로.
- PC 레이아웃(750px, REA): 왼쪽 카드 = "2년 전 성적표 98.6점 ○○, 24% 올랐습니다" 큰 제목 → 1·2·3위 행(단지·당시 점수·평형 / "과거가 > 현재가" / "2년간 N% 상승" 배지) → 작은 회색 각주("2024.08 기준으로 다시 계산한 점수가 높은 순서이며, 이후 2년 시세 변동을 함께 보여 줌. 개별 단지 결과를 보장하지 않음") — **점수의 기준 시점·계산 방식·한계를 같은 카드 하단 각주로** 붙인다.
- 우리에게 쓸 만한 패턴:
  - 한 값 앞에 짧은 종류 라벨("실", "호가")을 붙여 같은 칸에 두 값을 둘 때 구분 — 우리 라벨 배지(공식·추정)를 숫자 바로 앞 짧은 글자로.
  - 점수·예측을 보여주는 카드는 **기준 시점 + 계산 방식 + "보장하지 않음"** 각주를 같은 카드 안에 둔다(우리 판정기 점수 표시 + "투자 권유 아님 · 상대 비교" 고정 문구와 같은 방향).
  - 모바일 필터 = 상단 칩 한 줄 + 시트.
- 맞지 않는 것: 앱 설치 배너·하단 "앱으로 보기" 고정 바, "○억 예상" 집값 예측 티커(판정기 밖 예측 — 우리는 만들지 않음), 경매 말풍선의 "저렴/비쌈" 평가어.

## 리치고 모바일 — 청약 목록 (https://m.richgo.ai/realty/parcel/home, 관찰일 2026-10-14, evidence_id richgom-parcel-mobile)

- 첫 화면에서 가장 먼저 보이는 것 3개: (1) 큰 제목 "청약" + 세그먼트 탭 [청약 일정 | 지난 청약], (2) 지역 칩 가로 스크롤 — **칩 안에 "(N개 청약중)" 개수**(전국 선택이 검은 채움), (3) 파란 "6개 청약 중" 요약 줄 + 단지 카드.
- 정보 계층(카드 하나, 모바일 4줄):
  1. 회색 작은 줄: 지역(시도 시군구) + 시행·시공사(연한 색).
  2. 굵은 단지명(한 줄 말줄임).
  3. **파란 큰 글자 상태**: "1순위 청약중", "2순위 청약중", "청약임박 D-5", "26년 10월 청약예정" — 상태와 남은 날(D-n)을 한 덩어리로.
  4. "세대수 | 분양가 최저~최고 | ±금액 비쌈!/저렴!" (세로 구분선).
  - 오른쪽: "알림받기" 버튼.
- 묶음 단위: 섹션 2개(청약중 → 청약예정), 세로 카드 목록, 카드 사이 광고 배너 1개.
- 숫자 표기: 분양가 범위 "4.7억~12.4억"(억 소수 첫째 자리, 범위는 물결), 세대수 천 단위 쉼표 "1,128세대", 차액 "672만", "1.6천"(천만원 축약).
- 상태·라벨 표현: 상태 텍스트가 카드에서 가장 눈에 띄는 색·크기(단지명 다음 2순위 무게). 섹션 제목 "청약예정"으로 단계 그룹핑.
- 필터·정렬: 지역 칩(기본 전국), 정렬은 상태 → 날짜 순으로 보임. 접는 방식 없음(무한 목록).
- 용어 처리: 없음.
- 모바일에서 달라지는 것: 표 대신 4줄 카드. 수치는 줄 4 하나에만 모으고 세로 구분선으로 나눈다.
- 우리에게 쓸 만한 패턴(우리 말로):
  - 모바일 단지 카드 4줄 = **지역(회색) → 단지명(굵게) → 상태 + D-n(강조색 큰 글자) → 핵심 수치 한 줄(세대수 | 분양가 범위)**. 우리 G2 모바일(읽기 전용) 카드 구조 후보. 상태 강조는 색만이 아니라 글자로(D7).
  - 지역 칩 안에 해당 지역 진행 건수를 괄호로 — 필터를 누르기 전에 결과 수를 알 수 있음.
  - 목록 머리 "N개 청약 중" 요약 한 줄.
  - "청약중 / 청약예정" 단계별 섹션 분리.
- 맞지 않는 것과 이유: "○만 비쌈!/저렴!" — 비교 기준(무엇 대비인지)이 카드에 표시되지 않은 평가어. 우리는 비교값을 보여주더라도 기준·출처를 함께 붙이고 평가어는 쓰지 않는다. 목록 중간 광고 배너.

## 리치고 모바일 — 분양 단지 상세 (https://m.richgo.ai/realty/parcel/a6YvYHm, 관찰일 2026-10-14, evidence_id richgom-parceldetail-mobile)

- 묶음 단위: 섹션 앵커 탭 + 섹션마다 "제목 → 요약 문장(기준 범위 포함) → 차트 → 표". 모든 차트 아래 같은 데이터 표가 붙는다.
- 숫자 표기: 평당가 "1,509만", 차트 축 "500만 / 1천 / 1.5천", 거리 "km 소수 첫째", 연식 "N년차", 경쟁률 "4:1", 날짜 "26.01".
- 상태·라벨 표현: 미정·미공개를 **값 자리에 단어로**("미정"), 섹션 빈 상태는 "아직 ~않았어요" 문장 + 행동 버튼, 비교 표에서 대상 단지 값은 "-". 요약 문장에 기준 범위("제주 서귀포시 아파트 기준", "최근 5년")를 넣는다. 출처는 페이지 맨 아래 출처 표로 모음.
- 필터·정렬: 표 열 정렬, 입주물량 범위 토글(시군구/반경).
- 용어 처리: 없음(당첨가점·미분양 등 무설명).
- 모바일에서 달라지는 것: 이 자체가 모바일 레이아웃 — 섹션을 세로로 쌓고, 표는 5열 이내, 탭은 가로 스크롤 앵커.
- 우리에게 쓸 만한 패턴(우리 말로):

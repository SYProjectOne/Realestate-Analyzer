## R-ONE — 홈 통계 대시보드 (https://www.reb.or.kr/r-one/, 관찰일 2026-10-14, evidence_id rone-home-rea-desktop, rone-home-desktop)

- 첫 화면에서 가장 먼저 보이는 것 3개(크기·위치 순):
  1. 첫 진입 시 화면 가운데를 덮는 홍보 팝업("주택동향 1분 안에 알아보기" 류 영상 안내). 닫기 전에는 본문을 가린다.
  2. 큰 제목 + 통합 검색창(옆에 AI 질의 버튼).
  3. 8장의 통계 카드 격자(4×2). 각 카드 = 통계명 / 기준월 / 지표명(단위) / 대상 유형 / 값.
- 정보 계층:
  - 1단(요약): 카드 8장 — "어떤 통계의, 언제 기준, 무슨 지표가, 얼마"를 한 카드에 모두 담는다. 결론 문장은 없다.
  - 2단(핵심 수치): "지역별 매매가격지수 변동률 – 아파트 (2026년 8월) (단위: %)" 블록 — 전국값, 상위 2개 지역, 하위 2개 지역을 먼저 요약하고 그 아래 시도 지도(색 구간 범례 5단계)와 지역별 값 목록.
  - 3단(상세): "변동률 추이(최근 3개년)" 선 차트(36개 점) ↔ "지역순위" 탭, 그다음 빠른통계찾기·공표보고서·보도자료 목록(썸네일 링크) → 통계DB로 연결.
- 묶음 단위: 카드(헤드라인 지표), 지도+목록(지역 비교), 탭(추이/순위 전환), 썸네일 목록(보고서·보도자료).
- 숫자 표기:
  - 카드마다 기준 시점이 각자 붙는다(같은 화면에 "2026년 8월"과 "2026년 7월", "2026년 2분기"가 섞여 있어도 카드 단위로 정확히 표시).
  - 단위는 지표명 뒤 괄호 "(%)", "(호수)", "(필지수)". 변동률은 소수 둘째 자리, 지가는 셋째 자리.
  - 부호에 따라 값 색이 바뀌지만(상승/하락) 부호(−)도 같이 쓴다 — 색만으로 의미를 전하지 않는다.
  - 지도 범례는 "−0.25% 초과 ~ 0.25% 이하"처럼 구간 경계를 문장으로 명시.
- 상태·라벨 표현: 각 카드 우상단에 달력 아이콘 + 기준월. 지역 블록 제목 옆에 "(2026년 8월)(단위 : %)". 범위 제한은 "(참고) ○○ 통계는 시군구 선택 불가"처럼 블록 바로 아래 각주로 적는다. 하단 푸터에 통계별 담당 부서 전화번호(통계 문의처)를 나열 — 출처 책임 주체를 화면 안에서 밝힌다.
- 필터·정렬: 지도에서 시도 클릭 → 시군구 펼침("지역 한번 클릭 시 시군구 확인 가능" 안내문). 기본값은 전국.
- 용어 처리: 용어 설명은 거의 없음(전문가용). 대신 "1분 안에 알아보기" 영상·카드뉴스로 외부 학습 경로를 제공. 차트는 Highcharts 접근성 모듈로 "View as data table" 버튼이 있어 차트를 표로 열 수 있다.
- 모바일에서 달라지는 것: 관찰하지 않음(이번 라운드 데스크톱만 — 관찰 불가 아님, 범위 밖).
- 우리에게 쓸 만한 패턴:
  - 헤드라인 수치 카드에 "통계명·기준 시점·지표명(단위)·대상"을 카드 안에 같이 넣는다. 카드마다 기준일이 다를 수 있으면 카드마다 따로 적는다(우리 FactCell + 확인일 표기와 같은 방향).
  - 지역 비교는 "전체값 → 상위 2 → 하위 2" 요약을 먼저, 지도·전체 목록은 그 아래.
  - 색 구간 범례는 경계값을 글자로 쓴다.
  - 차트마다 "표로 보기"를 붙인다(D7 "차트 데이터는 표로"와 일치).
  - 화면 안 범위 제한·예외는 해당 블록 바로 아래 "(참고)" 각주로.
- 우리에게 맞지 않는 것과 이유: 첫 진입 전면 팝업(본문 차단 — 초보자에게 첫 3초를 낭비시킴). 카드 8장이 같은 크기·같은 무게라 "무엇을 먼저 볼지"는 알려주지 않음(우리 문제와 같은 증상).

## R-ONE — 통계DB 통계표 검색 (https://www.reb.or.kr/r-one/portal/stat/easyStatPage.do, 관찰일 2026-10-14, evidence_id rone-statdb-rea-desktop)

- 첫 화면에서 가장 먼저 보이는 것 3개: 좌측 "통계표검색" 패널(분야별/명칭별 토글 + 검색), 폴더 트리(작성 통계리스트 → 조사별 폴더), 우측 기관 소개 이미지(표를 고르기 전 빈 상태).
- 정보 계층: 1단 = 통계 종류 트리, 2단 = 선택한 통계표, 3단 = 표 원문·다운로드. 결론 요약 없음.
- 묶음 단위: 트리(폴더) + 오른쪽 표 영역. "★ 자주 찾는 통계표" 폴더를 맨 위에 둔다.
- 숫자 표기: 표 선택 전이라 관찰 범위 밖.
- 상태·라벨 표현: 트리 항목 옆 작은 아이콘으로 "국가승인통계" 여부를 표시하고, 패널 상단에 아이콘 범례(국가승인통계 / 지도)를 둔다. 자체 작성 통계와 "타기관 통계리스트"를 폴더 수준에서 분리 — 출처 기관이 다른 자료를 섞지 않는다.
- 필터·정렬: 분야별(기본) / 명칭별 토글, 전체목록받기 버튼.
- 용어 처리: 도움말 버튼(상단), 그 외 없음.
- 모바일에서 달라지는 것: 범위 밖.
- 우리에게 쓸 만한 패턴: "공식 통계 / 다른 기관 자료"를 목록 단계에서 분리하고 아이콘+범례로 신뢰 등급을 표시하는 방식은 우리 라벨(공식·재가공·추정)의 텍스트 배지와 같은 역할. 빈 상태(아직 아무것도 고르지 않음)에 무엇을 하라는 안내 대신 소개 이미지가 나오는 점은 반면교사.
- 우리에게 맞지 않는 것: 전문가용 트리 탐색 — 초보자 대상 화면의 1단으로는 부적합.

## R-ONE — 테마통계 "차트로 보는 부동산통계 흐름" (https://www.reb.or.kr/r-one/portal/stat/chgRate/tradeChgStatsPage.do, 관찰일 2026-10-14, evidence_id rone-theme-rea-desktop)

- 첫 화면에서 가장 먼저 보이는 것 3개: 페이지 제목 + 한 줄 설명("원하는 기간 설정을 통해 변화 흐름을…"), 6개 통계 탭, 조회 조건 바(조회시점·기준시점·월간/주간·지역·유형·적용).
- 정보 계층:
  - 1단: 조건 바 왼쪽의 **"조회시점: 2026년 8월"**과 **"기준시점: 2026.06.=100.0"**(경고 아이콘·강조색). 숫자를 읽기 전에 "언제 기준, 무엇을 100으로 놓았는지"를 먼저 보여준다.
  - 2단: 블록 제목 "전국 주택종합 가격 변동률 추이"(지역명만 강조색) → 막대 차트(매매·전세·월세 3계열, 12개월, 막대 위 값 라벨).
  - 3단: 차트 바로 아래 요약 표 — 행: 지수 / 전월 대비 / 전년말 대비 / 직전 3년·5년·10년 같은 달 평균 변동률, 열: 매매·전세·월세. 그 아래 "기준시점 대비 비교"(기준 연도 선택).
- 묶음 단위: 탭(통계 종류) → 조건 바 → 제목 카드 → 차트 → 표. 차트 우상단에 차트저장·엑셀·전체화면.
- 숫자 표기: 지수는 소수 둘째 자리(100.68), 변동률 소수 둘째 자리. 비교 기준을 행 이름에 문장으로 쓴다("전월 대비", "전년말 대비", "직전5년 08월 평균").
- 상태·라벨 표현: 기준시점을 경고색 아이콘과 함께 조건 바에 고정. 출처는 사이트 자체가 작성 기관이라 별도 출처 줄 없음.
- 필터·정렬: 기본 전국·주택종합·월간. 시도 → 세부지역 2단 콤보. "적용" 버튼을 눌러야 반영(즉시 반영 아님).
- 용어 처리: 없음. "지수", "기준시점=100"을 설명 없이 사용 — 초보자에게는 어렵다.
- 모바일에서 달라지는 것: 범위 밖.
- 우리에게 쓸 만한 패턴:
  - 시계열 위에 "조회시점 / 기준시점"을 한 줄 바로 고정 — 우리 시장 대시보드(G6)·보고서 차트 머리에 "기준일 · 비교 기준"을 같은 위치에 둔다.
  - 차트 바로 아래 같은 데이터를 요약 표로(전월·전년말·과거 평균 대비) — 차트-표 병치, 비교 기준이 행 이름에 문장으로 들어감.
  - 블록 제목에서 지역(변수)만 강조색으로 표시해 "지금 무엇을 보고 있는지"를 알린다.
- 우리에게 맞지 않는 것: 지수·기준시점 개념을 설명 없이 쓰는 것(초보자 persona에 부적합 — 우리는 괄호 설명/툴팁 필요).

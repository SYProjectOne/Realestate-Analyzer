## 밸류맵 — 홈 (https://www.valueupmap.com/, 관찰일 2026-10-14, evidence_id valueupmap-home-rea-desktop)

- 첫 화면에서 가장 먼저 보이는 것 3개: (1) 중앙 대형 광고 모달(3일간 보지 않기/닫기), (2) 좌측 검색창 + 4개 큰 버튼(실거래·매매·임대·경매) + 필터 2개, (3) 지도 위 거래 말풍선(용도 라벨 "근린/업무/다가구" + 금액 + 거래연월 "24.08").
- 정보 계층: 1단 = 동 이름 + "총 N개" + 매물 카드, 2단 = 카드(거래유형 배지·사진·"N일 전"·조회수 / "매매 98억" / "일반건물 · 구 동" / 대지면적·연면적·규모·노후도 4칸), 3단 = 상세.
- 묶음 단위: 지도 + 좌측 목록 카드, 지도 상단 "○○동 신규 실거래 (09.22)" 알림 칩.
- 숫자 표기: 억 단위 소수 첫째 자리, 거래연월 "YY.MM", 면적 "평", 노후도 "N년".
- 상태·라벨 표현: 말풍선마다 용도 텍스트 라벨(근린·업무·숙박·대지 등) + 거래 구분(매매·낙찰·확인). "NEW" 칩.
- 필터·정렬: 필터 패널은 섹션 제목(거래년도·부동산유형·지목·용도지역·금액·면적) + 버튼 칩 나열 + **섹션마다 "이 필터가 무엇을 검색하는지" 회색 한 줄 설명**("실거래의 거래년도, 매물의 등록시점 년도, 경매의 감정·낙찰시점 년도를 검색"), 범위는 미리 정한 구간 칩(~10억 / 10억~30억 …) + 직접입력, 하단 단위·초기화·필터저장·확인. 목록 정렬 "기본 순 / 최신 순", "단가로 보기" 체크박스.
- 용어 처리: 필터 섹션 설명문, 제한 고지("APT/연립 유형은 경매에서만 확인할 수 있습니다").
- 모바일: 범위 밖.
- 우리에게 쓸 만한 패턴: 필터 섹션마다 회색 한 줄로 "이 조건이 무엇을 기준으로 거르는지" 설명. 범위 필터는 구간 칩 + 직접입력. 지도/목록 위 "신규 ○○ (날짜)" 알림 칩.
- 맞지 않는 것: 진입 광고 모달, 상단 메뉴의 부가 서비스(설계·STO·스토어 등) 과밀.

## 밸류맵 — 실거래 상세 (https://www.valueupmap.com/properties/trades/1111017400106510044, 관찰일 2026-10-14, evidence_id valueupmap-trade-rea-desktop)

- 첫 화면에서 가장 먼저 보이는 것 3개: (1) 멤버십 홍보 모달("모든 정보 열람" 유도), (2) 상단 가로 앵커 탭 13개(기본정보·신축검토·밸류맵 시세·과거 거래내역·토지정보·건축물대장·업종현황·유사부동산 거래분포·대출정보·신규 실거래·유사 거래사례·개발정보·인근매물), (3) 지적도 위 필지 하이라이트 → 그 아래 "실거래 배지 + 거래시점 11.05" / 큰 금액 / 용도 / 주소(+도로명 전환 버튼).
- 정보 계층:
  - 1단: 상태 배지("실거래") + 거래시점 + **큰 금액(6.5억)** + 용도 + 주소.
  - 2단: 3칸 요약 박스 — 시세(날짜 칩 26.09.28) / 과거호가 / 등기상 대출금액(두 칸은 "멤버십 전용" 잠금 배지 + "없음/미열람" 상태 칩). 그 아래 키-값 2열: 총 대지면적(현재값 병기) · 토지단가(원/평) · 총 연면적 · 건물단가 · 용도지역 · 사용승인일("-").
  - 3단: 문서함(등기부등본·지적도·토지대장·건축물대장 "열람하기 >") → 밸류맵 시세 "최근 가격정보" 한 줄(시세·과거호가·실거래가·경매가·건축/토지 변경·개별 공시지가 — 항목마다 날짜 + 값, 없으면 "-") → 과거 거래내역(모두보기) → 토지정보 → 토지이용계획(포함/저촉 구분) → 건축물대장 → 업종현황("2026.3분기 기준") → 유사부동산 거래분포(최근 1/3/10년 토글, "최근 10년 평균 단가(2016~2026)") → 대출정보.
  - 우측 레일: 지역 평점 카드(별점·항목별 별) + 리뷰 수 — 판단 성격.
- 묶음 단위: 긴 단일 스크롤 페이지 + 상단 앵커 탭(스크롤 이동). 섹션 = 제목 + 키-값 또는 표. 원문 문서는 "문서함"으로 따로 묶음.
- 숫자 표기: 금액 "6.5억", 단가 "27,199,498원/평"(원 단위 전체), 공시지가 이력 "3.8천/평"(천만원 축약), 면적 "23.9평 (현 23.9평)" — 거래 당시 값과 현재 값을 괄호로 나란히. 날짜 "26.09.28", "26.01".
- 상태·라벨 표현:
  - 섹션마다 기준 시점을 제목 옆에("2026.3분기 기준", "최근 10년 평균 단가(2016~2026)").
  - 값 없음 "-", 잠금 "멤버십 전용", 미조회 "미열람/열람내역이 없어요".
  - 거래 시점 값과 현재 값 분리 표기("현").
- 필터·정렬: 거래분포 기간 토글(최근 1년·3년·10년), 지역 구분 토글(전체·상업·주거).
- 용어 처리: 없음(전문 용어 무설명). "이력정보 요약" 버튼(토지 이력 요약).
- 모바일: 범위 밖.
- 우리에게 쓸 만한 패턴(우리 말로):
  - **"최근 가격정보" 한 줄 타임라인**: 서로 다른 출처의 값(실거래·공시·호가·경매)을 한 줄에 나란히, 각 칸에 날짜와 값, 없으면 "-". 우리 G3 "가격 근거" 블록(분양가·주변 실거래·공시)을 한 줄 요약으로 묶고 각 칸에 출처 라벨·확인일을 붙이는 구조 후보.

  - 섹션 제목 옆 "○○ 기준" 시점 표기.
  - 원문 문서(등기·대장)를 "문서함" 한 곳에 모아 "열람하기 >" — 우리 출처 패널(ProvenancePanel)을 한 번 클릭으로 여는 구조와 일치.

- 맞지 않는 것과 이유:

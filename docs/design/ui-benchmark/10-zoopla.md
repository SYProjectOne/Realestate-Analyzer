## Zoopla — 런던 신축 목록 (https://www.zoopla.co.uk/new-homes/property/london/, 관찰일 2026-10-14, evidence_id zoopla-list-desktop)

- 첫 화면에서 가장 먼저 보이는 것 3개: (1) 쿠키 동의 창, (2) 상단 위치 입력 + 반경·방·가격·유형·필터 + 저장, (3) 제목 + 결과 수 + 첫 카드(사진 위 배지 2개: 이주의 매물 / 신축).
- 정보 계층: 1단 제목·결과 수·정렬(추천순) → 2단 카드(배지 / 사진 / 방·거실 수 / 세대명·주소) → 3단 오른쪽 보조 열(알림 만들기, 검색 저장, 통근 시간 검색, 직접 그려 찾기, 지역 안내).
- 묶음 단위: 세로 카드 + 오른쪽 행동 열.
- 숫자 표기·상태: 신축은 색 배지에 글자를 넣는다. 결과 수는 제목 아래 회색 작은 글씨.
- 필터·정렬: 기본 정렬 "추천순". 필터 버튼에 적용 개수 표시(1).
- 용어 처리: 없음.
- 우리에게 쓸 만한 패턴: 필터 버튼에 적용된 조건 수를 숫자로 표시한다(지금 무엇이 걸러졌는지 알 수 있다).
- 맞지 않는 것: "이주의 매물" 같은 유료 노출 배지, 추천순 기본 정렬.

## Zoopla — 신축 세대 상세 (https://www.zoopla.co.uk/new-homes/details/71803618/, 관찰일 2026-10-14, evidence_id zoopla-detail-desktop)

- 첫 화면에서 가장 먼저 보이는 것 3개: (1) 큰 사진 + 사진 위 "방금 등록" 배지 + 사진 아래 자료 버튼 줄(사진 n장, 가상 투어, 브로셔, 평면도, 지도, 거리뷰), (2) 사진 아래 **가장 큰 글씨의 가격** + "월 비용 보기(ⓘ)" + 평당가(괄호, 회색), (3) 오른쪽 개발사 카드(개발사·단지명, "개발 단지 정보 보기", 전화·문의).
- 정보 계층:
  - 1단(요약): 가격 / 월 비용 진입 / 평당가 / 제목(방 수 + 유형 + 주소) / 배지(신축, 보유 형태) / 방·욕실·면적 / 에너지 등급 / 등록일.
  - 2단(핵심 수치): **"핵심 정보" 영역**: 보유 형태(잔여 연수 포함), 관리비(연), 지방세 등급, 토지 임차료, 다음 임차료 재평가일. 항목마다 설명 버튼이 있고, 값이 없으면 "중개사에 문의" 링크를 단다. 끝에 "공공요금 및 기타 상세"(접기).
  - 3단(상세): 특징 목록 → 전체 설명(접기) → 도구(모기지 계산기, 취득세 계산기, 둘 다 "참고용, 금융 조언 아님" 고지) → 지역 정보·학교 → 개발사 소개 → 인사이트(로그인 필요) → 기타(신고하기).
- 묶음 단위: 영역(region) 단위 카드. 핵심 정보는 목록형. 계산기는 폼.
- 숫자 표기: 가격 옆 평당가를 괄호와 회색으로 낮춰 둔다(보조 수치는 무게를 낮춘다). 관리비는 "연" 단위를 붙인다. 보유 형태에 남은 기간을 괄호로 붙인다.
- 상태·라벨 표현: 단지(개발 단지)와 세대가 분리되어 있고, 오른쪽 카드에서 "개발 단지 정보"로 올라간다. 신고하기 링크가 있다.
- 용어 처리: **핵심 정보 항목마다 같은 이름의 설명 버튼**(Rightmove와 같은 패턴). 계산기 아래 고지 문장.
- 모바일: 관찰 못 함.
- 우리에게 쓸 만한 패턴:
  - **"핵심 정보" 상자 = 초보자가 계약 전에 알아야 할 조건만 모은 목록**(보유 형태·관리비·지방세). 우리 G3에 "청약 전 꼭 볼 조건" 상자(전매제한, 거주의무, 실거주, 재당첨 제한, 중도금 대출 여부)를 두고 항목마다 설명 버튼을 단다. 값과 출처 라벨은 그대로 보여준다.
  - 주 숫자 1개는 크게, 보조 수치(평당가)는 괄호와 회색으로 낮춘다.
  - 값이 없으면 "문의 필요" 같은 상태 문구로 채운다.
  - 단지(개발) ↔ 세대 사이 이동 링크를 오른쪽 카드에 고정한다.
- 맞지 않는 것과 이유: 은행 제휴 계산기·대출 가능액 링크(금융 상품 유도), 인사이트 로그인 벽. 우리는 대출·세금 계산을 하지 않는다(판단 금지). 공고 값만 보여준다.

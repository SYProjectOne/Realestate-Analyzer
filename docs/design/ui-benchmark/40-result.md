## 2. 첫 화면 3초 테스트 재채점

채점: 초보가 실제로 먼저 읽는 3개가 "먼저 읽어야 하는 것"(00-baseline 표 오른쪽 열)과 몇 개 겹치는가(0~3).

### G1 홈 — **0/3 → 3/3**

| | 전(before-g1-desktop) | 후(after-g1-desktop) |
|---|---|---|
| 1 | 큰 숫자 5개 `12` · `3` · `2,029세대` · `2028` · `2026-10-08 (D-day)` — 무엇의 개수인지 맥락 없음 | **지금 접수 가능 3곳** + "접수 가능 단지 보기" 링크 + 기준 설명 |
| 2 | 오른쪽 최근 변경의 내부 필드·해시(`down_payment_pct 10 → 5`, `popup_image_hash 9be1…`) | **다가오는 일정(4주)**: `중도금 납부 2026-10-15 (D-7) 풍무역 롯데캐슬…`, 접수일 미수집 안내 |
| 3 | TOP 카드 `종합 5.87` · `+10% 확률 39%` · `rerank 변화(이전 run 대비) 0.00` | **상위 단지 카드의 현재 구매가 · 전매 종료 · 가격 갭**, 그 아래 종합 점수·+10% 상승 가능성(목표 시점·"당첨 확률이 아닙니다") |

모바일(after-g1-mobile): 지금 접수 가능 → 다가오는 일정 → 상위 단지 카드 순서. 가로 넘침 0.

### G2 단지 리스트 — **1/3 → 3/3**

| | 전 | 후 |
|---|---|---|
| 1 | 필터 10칸(2줄) | 목록 안내 한 줄 + 핵심 필터 3칸 + "지금 접수 가능만 보기" 칩(1줄) |
| 2 | 단지 이름 + `확인됨` 테두리 배지가 칸마다 | **단지 이름(생활권 아래 줄) + 접수 상태**(배지는 상태만, 사유는 아래 작은 글씨) |
| 3 | 접수 열 배지 | **현재 구매가 · 계약금 비율 · 전매 종료**(확인됨은 회색 글자라 숫자가 먼저 읽힌다) |

| | 전 | 후 |
|---|---|---|
| 1 | 이름 + 같은 무게 배지 5개 | 이름 · 생활권 · 총 세대 · 입주 → **지금 상태**(접수 가능 · 현재 적용 공고: 임의 · 일정 · 당첨자 발표 D±) |

| 3 | 가격표 8열(칸마다 배지) | **청약 전 꼭 볼 조건**: 전매 종료(팔 수 있게 되는 날) · 거주의무 0개월 · 재당첨 제한 10년 · 규제지역 비규제 · 분양가 상한제 적용 · 공급 |

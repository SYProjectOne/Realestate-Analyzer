그림으로 그리지 않은 것 (기능은 유지)

  • 차트 갤러리(/__charts) — 개발할 때만 쓰는 화면이라 사용자 목업에서 뺐어요. 그대로 남겨요.
  • 타입별 가격의 '할인' 열 4가지 모양 — 이 단지(시티오씨엘 8단지)에 할인이 없어 문구로만 적었어요.
  • 타입별 가격 · 납부 일정 탭이 비었을 때 — 다른 "없음" 상태와 모양이 같아 따로 그리지 않았어요.
  • 생활권 편집 '공급 기준치' 문구 — 문구 파일에만 있고 지금 화면 코드에서 쓰지 않아요.
  • 키보드 ← → 탭 이동, 긴 표의 부드러운 스크롤 — 동작이라 문구로만 적었어요.

실제로 옮길 때 지킬 것

  1. 지금 있는 자동 테스트(화면 수락·출처 보존·라벨·e2e 흐름 7개·접근성·성능)를 그대로 통과해야 합쳐요. 기능이 빠지면 테스트가 먼저 실패해요.

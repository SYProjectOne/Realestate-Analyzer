아직 정할 것 (구현 때)

  • API에 값이 없는 곳 — 지역 시장 미분양 지역 합계, 상세 머리의 주변 거래 중간값·가점 범위, 홈 "공식 자료 n곳", 운영 모순 주장 내역. 목업에는 [값] + "API 필요".
  • 서버 문구 — 요건 이유의 "P_mid", 점수 계산 범위 사유의 영어 분류명. 화면은 서버 문자열을 그대로 보여야 해서 서버 쪽 문구를 고쳐야 해요.
  • 작은 것 — 작업 이름 쉬운 말 표, '접수 일정 미정'/'접수 미정' 이름 통일, 카드 보기에도 점수 표시, 휴대폰 메뉴 위치(위/아래).
  • 남은 빠짐 1개 — 생활권 편집 '공급 기준치' 문구: 지금 코드가 쓰지 않아 그리지 않았어요.

실제로 옮길 때 지킬 것

  1. 지금 있는 자동 테스트(화면 수락·출처 보존·라벨·e2e 흐름 7개·접근성·성능)를 그대로 통과해야 합쳐요.
  2. 대응표 1,996줄을 구현 체크리스트로 써요. 줄마다 새 화면 테스트 이름을 붙여요.
  3. 숫자·라벨·출처는 서버 값 그대로예요. 화면이 새 숫자를 계산하거나 판단 문장을 만들지 않아요(개수 세기만 허용).
  4. 문구는 지금처럼 한 파일(ko.json)에서만 바꿔요.

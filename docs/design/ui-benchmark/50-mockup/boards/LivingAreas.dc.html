인천을 어떤 동네 묶음으로 볼까요?

생활권은 출퇴근·학교·장보기처럼 생활이 이어지는 동네 묶음이에요. 시세·입주 물량·근처 단지 비교를 이 묶음 단위로 계산해요.

동(법정동)을 옮겨 묶음을 나누거나 합쳐요. 모든 동은 꼭 한 생활권에만 들어가야 해요.

지역 범위를 넓히거나 줄일까요?

지금 고른 곳에 시도·시군구·동을 더하거나 빼요. 저장하면 같은 기준일의 새 수정본에서 모든 후보 단지의 순위를 다시 매기고, 보고서에 '지역 추가' 장(이전 수정본과 비교)이 생겨요. (공식 이름: 지역 범위 확장)

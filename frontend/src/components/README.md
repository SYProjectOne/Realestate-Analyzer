# src/components — 공통 컴포넌트 계약 (WP0-C 고정, 계약 2026-10-09.1)

- **주인**: WP6b (구현·개선). **사용자**: WP6a (화면 G0~G8).
- 아래 **props 타입이 계약**이다. WP6b는 내부 구현(모양·접근성·세부 동작)을 자유롭게 바꾸되 props를 깨지 않는다. 필요한 변경은 _추가(optional prop)_ 로만 하고, 이름 변경·삭제는 CEO 승인 후.
- 화면은 `@/components`(index.ts)에서만 import 한다.
- 문자열은 전부 `src/i18n/ko.json` → `t()`. 숫자는 `FactCell` 또는 `src/lib/format.ts`로만(ESLint `local/no-raw-number-render`).
- 라벨·상태는 **색이 아니라 텍스트 배지**(D7). 배지 바탕은 `Badge`(tone: neutral | muted(회색) | strong).
- 데이터 타입은 `@/api/types`(임시 → 계약 머지 후 생성 타입 별칭)에서 온다.

## WP6b 완성 — 하위 호환 확장 (R1)

props 이름·의미는 그대로, 타입만 넓혔다(임시 `@/api/types`와 계약 생성 타입 둘 다 대입되는 구조 타입 `src/lib/contract.ts`의 `*Like`).

- 표시 문자열 = 계약 `fact.json`·`intake.json` 규칙: `확인 불가(<사유>, <확인일>)`, `<라벨>(<한정어>)`(예 `추정(대체·보정 c=0.015)`), `사람 확인됨`. `LabelBadge`에 `checkedAt?`, `EmptyState`에 `checkedAt?` 추가.
- `FactCell.unit`은 optional — 생략하면 계약 `fact.unit` 힌트(won·units·prob·ym …)로 포맷. FactUnit에 `units`·`year`·`months`·`years`·`m` 추가.
- `IntakeBadge`: 확인 불가·불가면 `접수 확인 불가(403, 2026-10-07) · 공식 팝업`.
- `ProvenancePanel`: 값·라벨(사유)·확인일·원문 주소·출처 종류/순위·HTTP 상태·산출식(sc_/st_)·판정 로그 번호, 발췌 안 값 `<mark>`, **"원문에서 보기"** = `GET /raw/{id}?as=text`의 `excerpt_start~end` 하이라이트, **상충 그룹**(본 출처 + conflicts, 채택/미채택 배지, "이 출처 열기"로 패널 안 이동). Esc·닫기 버튼, 열릴 때 닫기 버튼에 포커스.
- `RegionPicker`·`SnapshotPicker`·`ScenarioToggle`: `id`·`value`에 숫자(계약 id)도 받는다. `onChange`는 항상 문자열. SnapshotPicker 옵션에 `degraded`("일부 수집 실패")·`building` 표시.
- `JobProgress.jobId`는 `string | number`, `JobProgressView`는 계약 `progress{done,total,step}`를 결정 진행 막대로.

## FactUnit (src/lib/format.ts)

`won`(7억 4,900만원) · `eok`(7.49억) · `pct`(이미 % → 12.3%) · `prob`(0~1 → 48%) · `m2`(84.97㎡) · `date`(2026-10-11 (D-3)) · `ym` · `score`(7.26) · `households`(1,234세대) · `count` · `ratio`(12.3:1) · `rank`(1위) · `number` · `text`

## 레이아웃·전역 상태 (WP0-C 소유, 참고)

- `useScenario()` → `{scenarioId, setScenario}` (URL `?scenario=`), `useSnapshot()` → `{snapshotId, snapshot, snapshots, setSnapshot}` (URL `?snapshot=` → 지역 latest → 목록 첫 항목), `useActiveRegion()` → `{region, regions, isEmpty, setRegion}` (URL `?region=`).
- `useMobileLayout()` → `{isMobile, readOnly, unsupported}`. 모바일 읽기 전용 화면(G1·G2·G3)에서 쓰기 UI는 `readOnly`로 숨기거나 요소에 `data-write` 속성을 달면 CSS가 숨긴다.
- 하단 고정 문구 "투자 권유 아님 · 상대 비교"는 `layout/AppLayout`이 모든 화면에 붙인다.
- 쓰기 버튼은 `useCanWrite()`(`@/api/auth`)가 false(읽기 전용 토큰)면 `disabled` + `title=t('auth.readOnlyHint')`. 안내 배너·토큰 다이얼로그는 레이아웃이 붙인다.

## R2.5 추가

- `RawDocumentPreview` — props `rawId: number | string`, `defaultOpen?`, `className?`. "원문 미리보기"(GET /raw/{id}를 Bearer fetch → Blob: 텍스트는 `<pre>`, PNG 등 이미지는 object URL `<img>`, HTML·PDF는 저장 안내) · "원문 파일 저장"(`@/api/download`의 `useDownload`). 열 때만 받는다. `ProvenancePanel`·G3 출처 탭이 쓴다.
